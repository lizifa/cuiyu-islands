# 钓鱼界面与画面留白 · 0.7.2

## 问题与调整

用户截图中，底部面板同时承载提示、两条进度和四个按钮，覆盖人物、凳子与抄网。进度条占满横向空间，而“收线”“张力”标签使用通用自动换行，导致文字逐字竖排，进一步撑高面板。

取消底部大面板。日期下方改为顶部紧凑状态条，等待时只有一行提示，搏鱼时才显示收线与张力；固定标签宽度40逻辑像素并关闭自动换行，长提示单行省略。状态条不承载交互按钮，拖动其区域仍可控制镜头。常见横屏比例下等待高度不超过40，战斗完整状态不超过96逻辑像素。

咬钩、张力危险和等待抄网时，在浮漂或鱼附近显示短提示。提示约束在安全区内，避开人物投影、操作按钮、地图和其他HUD；若没有合适空间则不显示浮动提示，顶部状态及张力颜色、触感继续提供信息。普通等待降低提示强度，危险状态突出显示。

## 统一右下操作

| 原按钮 | 钓鱼期间 | 退出后 |
|---|---|---|
| 主交互 | 等待 → 提竿 → 收线 → 抄网 → 再甩竿 | 恢复附近物体交互 |
| 奔跑 / 加速 | 制饵或撒饵，角标显示饵料份数 | 恢复奔跑 / 加速，清空角标 |
| 建造 | 收竿离开 | 恢复建造 |

等待和动作过渡时主按钮不可误触；收线仍支持原生长按、松开卸力及空格。撒饵仅在等待且本竿未撒过时可用。收竿按钮不会误打开制造面板。左右操作区位置、尺寸与自定义布局保持原设置，临时标签和角标不写入布局存档。

“钓具与操作”移入右上菜单，打开沿用游戏说明的暂停弹窗流程。钓鱼期间隐藏任务、船状态及重复普通提示，保存失败等重要错误仍保留；退出恢复正常HUD。右上齿轮字符改为“设置”文字，避免截图中空白按钮的问题。

## 构图与边界

推荐钓鱼镜头略减少向浮漂方向的前瞻，使人物和凳子在画面内更完整，同时保留远投浮漂。沿用已有地形遮挡约束与手动镜头接管，不强制覆盖用户拖动后的角度。

不改变饵料成本、大鱼概率、张力规则、奖励、存档或触感设置。本次仅优化钓鱼HUD、对应临时操作和推荐取景，没有重做其他菜单与美术资产。
