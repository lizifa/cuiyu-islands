# 室内镜头与冰箱交互（0.17）

日常走动使用较远的室内视角，水平跟随半径由 5.2 米提升为 7.8 米，视野角 80°。目标放在人物上身附近，移动时朝行进方向少量前移，不跟随人物每次转身旋转。相机仍受室内包围盒和碰撞约束；外墙底部向下延伸封住原有缝隙，不增加重叠地板。

关键动作由 `home_camera.gd` 统一管理：保存原视角，平滑进入人物与操作目标的构图，动作结束/取消后恢复原方向及远景。冰箱、喝饮料、接水、烹饪和餐桌进食接入此规则，行走就位时不再使用通用交互系统突然改角度。专用交互期间暂不接受拖拽镜头，避免同时争夺控制。

冰箱交互顺序：

1. 走到可触及门把手的位置，停稳并面向冰箱。
2. 斜侧镜头同时呈现人物、门和储物层；伸手后门逐渐打开。
3. 从冰箱取出一瓶饮料，瓶子跟随可见侧的手臂收回；库存只扣一次。
4. 手持饮料沿安全方向后退，让开完整门扇扫掠区。
5. 用空闲手关门，瓶子保持在另一只手中；随后回到远景。
6. 点击喝饮料时，自然转向冰箱外的空地，使用斜前方镜头看清抬瓶、喝下和放低，不再硬转到固定世界方向。
7. 喝完产生空瓶，实际走到垃圾桶才丢弃。中断保留已取得的饮料或空瓶；暂停冻结当前动作。宠物在交互期间避开人物周围的操作区，不取消动物碰撞。

接水增加接杯与喝水动作，完成后才按原规则恢复饮水值；烹饪增加台前操作动作，完成后按原配方消耗 2 鲜鱼制作 1 鱼干。餐桌进食保留首次入口才消耗食物的规则，吃完退回远景。

楼梯仅允许右下交互按钮的一键上下楼。摇杆不触发楼梯、不接管自动过程；入口采用独立碰撞层的形状扫掠拦截普通行走，自动上下楼绕过这项拦截。该入口不参与镜头遮挡。保留原有连续行走、抬脚、转向平台及后方跟随。

电视按屏幕面积约翻倍放大，宽、高约为上一版的 1.414 倍，电视柜和落地灯同步调整，画框仍约 2 厘米；视频、音量及暂停逻辑保持原有功能。

开发验证使用 headless 测试和后台离线几何渲染，不打开编辑器、预览或手机游戏。离线图片用于检查构图与动作阶段，不等同于真机光照、触控、声音或温度验收。

2026-11-12 验证：46 组测试累计 2568 项检查通过，包含调整精确冰箱站位后对家庭流程、镜头、交互锚点和一键楼梯的重跑。六个阶段完成后台离线几何画面检查：日常远景、开门、取瓶、后退、关门和喝饮料。Release 0.17.0（38）覆盖安装到「小书包」iPhone 12 mini，保留应用数据、没有自动启动。签名检查与隔离目录内加载手机应用 PCK 的内容检查通过，确认远景参数、一键楼梯、放大电视、接水/做饭入口和完整电视视频已打包；未启用性能采样模式。尚未进行本版真机触控、观感及温度验收。
