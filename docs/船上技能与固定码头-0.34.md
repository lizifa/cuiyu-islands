# 船上技能与固定码头（0.34）

## 固定码头

四座周边岛屿各只有一个登岸码头，位于朝向主岛的一侧。码头有木栈桥、支桩、岛名和金色泊位标记，海图也标记码头。原来的四十八个隐形岸边候选点只用于生成时挑选一个安全泊位，不再分别开放登陆。

船距离泊位水平距离不超过 1.8 米，右下上方的「登岛」才亮起；主岛同样缩小到 1.8 米。点击后约两秒缓慢摆正并停稳，检查水域和船体碰撞，通过后下船。离泊位太远、仍在高速移动或者提交其他岸边坐标，都不能直接登陆；靠岸途中检测到障碍会停留在船上并提示重新调整。

登陆最后仍是从船转到码头内侧的安全陆地点，尚未制作人物沿跳板走上岸的完整动画。栈桥用于明确泊位位置，目前不提供自由行走的栈桥路径。

保留旧存档的岛上位置和原停船点，避免升级后丢失探索进度。返回自己的旧停船点后，新一次登陆使用固定码头。

## 五个船上按钮

- 大按钮：撒网 → 撒网中 → 收网 → 收网中。
- 左侧主按钮：按住加速，松开恢复普通速度。
- 上方主按钮：靠岸；附近有泊位才显示并启用「主岛靠岸」或「登岛」。
- 外侧小按钮：停船 / 继续航行。
- 外侧小按钮：返航主岛 / 取消返航。

保留三颗主要按钮的位置；小按钮没有额外大面板。上岸后恢复原来的情境按钮及「返回船上」。五个按钮均阻止触摸穿透到相机拖拽。

## 撒网与收网

点击撒网先停止推进、收桨，双臂转向船侧投网，渔网从船侧抛出并在空中展开；水面显示网线和八颗浮标。网放出后大按钮显示收网及百分比，最多等待二十秒；撒网、等待和收网期间禁止推进、加速、靠岸与返航。

点击收网后人物循环拉网，网和可见鱼模型逐步靠近船侧，约三秒后把鱼获放入背包的「鱼」资源，然后用一秒重新取桨，再恢复航行。等待越久收获越多（1～5 份），受背包容量限制。不会在撒网时直接给奖励，也不会因重复帧重复结算。暂停冻结动作和捕鱼进度。靠岸一侧没有足够水域时提示到开阔水面撒网。

渔网为本次出海的临时状态；存档或退出后回到既有安全岸点，不恢复未收起的网，也不预支鱼获。重置游戏会清理渔网、动作及移动锁。
