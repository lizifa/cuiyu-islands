# 「靠近＋面向即预选中」需求分析（2026-11-15）

## 一、你要的是什么（把口语翻成规则）

你的三句话其实是四层意思，我拆开：

1. **判定层**：能不能操作，只看两件事——离得够近、正面朝着它；不再看「有没有踩到某个固定站位点」。
2. **预选中层**：只要满足判定，五个技能槽立刻换成这台器材的技能（面板上就等于已经选中它），不用先走过去、再点一下才“激活”。
3. **执行层**：点下去直接开始，人物只做「原地转身 + 一小步吸附到操作位」，不再绕行到锚点。
4. **范围层**：不是只有哑铃，冰箱、沙发、餐桌、床、衣柜、浴室、摇椅、电视、电脑、灶台、水槽……所有预制体统一同一套判定。

一句话：**站位点从「门槛」降级成「姿态目标」**——以前是“必须站在 A 点才准用”，现在是“站哪都行，只要你对着它”。

## 二、现状盘点（逐个预制体查代码，不是猜）

| 预制体 | 现在怎么判能不能用 | 距离口径 | 有没有「必须先走到某点」 |

| 冰箱 | `nearby_action()` 选中 | 离冰箱本体 1.2 m | 无（选中即可用） |
| 垃圾桶补瓶 | `home_routine.gd:105` | **写死坐标 `(-6.4,.705,-2.5)` 1.5 m** | **有**（硬编码点，不是物体） |
| 水槽、灶台 | 点位 1.2–1.3 m | 物体本位 | 无 |
| 沙发 / 摇摇椅 | 点位 1.4 / 1.8 m | 物体本位 | 无 |
| 餐桌（4 把椅子） | 每把椅子各自一个点 1.8 m | 椅子本位 | 无（但选中哪把就看离哪把近） |

| 电视 | 点位 1.8 m | 物体本位 | 无 |
| 别墅门、上下楼梯 | 点位 1.4 / 3.2–4.2 m | 门口/楼梯口本位 | **有且合理**（进出与上下楼必须落在口上） |
| 钓鱼台、上船 | `FishingPlatform` / `BOARD_RADIUS` | 固定座位/船舷 | **有且合理**（玩的就是站位） |

结论：**真正“必须先走到某个位置”的只有 3 处**——健身四件套（已修）、垃圾桶补瓶（硬编码点）、床（只判距离不判朝向）。其余已经是“靠近就能用”，但**还缺一层“面向”**，而且选谁只看距离，不看你是不是对着它，所以你站在冰箱和灶台中间时，选中的可能是背对的那一个。

## 三、统一规则（建议版）

给每个预制体加一个统一的「可交互判定」，所有系统都调它，不再各写各的：

```
可交互 = 水平距离(人物, 物体中心) ≤ range
        且 朝向夹角 ≤ 阈值
        且 中间没有墙/家具挡住（现有 _clear 射线复用）
        且 楼层相同（二楼家具不能从一楼阳台点）
```

- **range**：沿用现有点位登记的半径（冰箱 1.2、沙发 1.4、餐桌 1.8、床 1.8、健身 1.9–2.6），不放大，避免隔着一屋子就能点。
- **朝向阈值**：建议 **±60°**（`dot ≥ 0.5`）。现在哑铃用的是 `dot ≥ 0.35`（±70°），可以统一收紧到 0.5，手感更“面向才算”。
- **预选中排序**：从「谁最近」改成「谁最正对」优先，距离次之。打分 `score = 距离 + 0.6·(1 − 朝向点积)`，分低者胜。这样你同时挨着冰箱和灶台时，**你对着的那个**才会亮技能。
- **执行**：点下去直接开始，人物只做原地转身（现有 `interaction_director` 已有「在 reach 内就用脚下这一格」的分支），不再寻路到锚点；坐、躺、锻炼这类需要贴合物体的动作，由系统自己把人物**平滑吸附**到操作位（现在 1.1 s 的 lerp 就有，可复用）。
- **例外（保留“必须到位”）**：别墅门进出、上下楼梯、上船、钓鱼台、阳台门。这些是「位置本身就是玩法」，不属于预制体交互。

## 四、落地改动清单（按影响面从小到大）

1. `life_world.gd` 新增 `interactable(point)`：距离 + 朝向 + 遮挡 + 楼层四合一；`nearby_action()` 改成「在 interactable 里按 score 取最优」。
2. `life_world.gd` 的 `facing_point()` 已有（本轮为健身加的），抽出来给全类型用，阈值默认 0.5。
3. `exercise_session`、`bed_session`、`home_routine`（垃圾桶）、`sofa_session`、`home_routine`（冰箱）各自把“写死坐标/锚点距离”换成 `world.interactable(point)`。
4. 垃圾桶：把硬编码 `Vector3(-6.4,.705,-2.5)` 换成垃圾桶物体的实际中心（`HomeBin` 节点位置）。
5. 床：加朝向判定（`villa_sleep` 面向床），并允许从床尾/床头两侧任意角度进入，只要不算背对。
6. 回归：`FIXED SKILL SLOTS`、`HOME INTERACTION PATHS`、`LIFE`，外加一个新用例：同一位置分别面对/背对冰箱，断言「面对才亮技能」。

## 五、需要你拍板的两个口径

1. **朝向阈值**：±60°（更严、更像“面向”）还是 ±70°（现在哑铃的宽松值，转身不用太准）？我建议 60°。
2. **椅子类**：餐桌有 4 把椅子，面向餐桌就算选中——但人会自动坐到**离你最近的那把**。要不要改成「面向哪把就坐哪把」？

另外：健身四件套的「靠近＋面向即可开始」**本轮已经先改好**（`begin()` 不再比对 anchor，改为「离器材 ≤ range 且 dot ≥ 0.35」，`nearby_action()` 也加了朝向过滤）。等你定了上面两个口径，我把冰箱、沙发、餐桌、床、衣柜、浴室、电视、电脑、灶台、水槽、垃圾桶一次性统一过去，再开模拟器实测。
