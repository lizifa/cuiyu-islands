# 室内扩建与餐饮生活闭环 · 0.15.0

按需求顺序实现：

1. 摇杆箭头使用与内圆完全相同的颜色和透明度；外层底色与描边默认显示为按下状态透明度的50%，按下时加强。保持扁三角贴内圆外缘、随方向转动与自定义布局能力。
2. 电视柜、电视与旁边落地灯向北移动1米，茶几不动，电视柜与茶几净距由2米增至3米。
3. 人物和家具保持正常尺寸，两层向南扩建：外包围19.6×12.2米变成19.6×24.4米，面积为原先两倍。新增的一楼空间用于餐桌活动；顶棚、地面、侧墙、正门、安全出生点、可行走范围、操作寻路网格、小地图中心和范围同步调整。卧室、楼梯与既有存档位置保留；净高仍为3.8米，室外别墅展示模型不变。每层用两个覆盖区域的灯源补足照明，控制灯光数量。
4. 靠近南侧餐桌点击“餐桌用餐”会走到椅子旁坐下。面板提供“吃东西”和“起身”；角色面对椅子朝向，双脚着地，手把食物送向嘴边。首口动作才调用既有食物消费规则，避免坐下即扣食物；暂停冻结动作，起身清理道具。屋内生活菜单也改成去餐桌坐下。
5. 厨房冰箱使用可实际旋转、带碰撞的门，里面可见6个瓶位。打开面板后可取一瓶或喝背包里的饮料；取瓶会先实际走近再伸手。库存初始6瓶，取出后保存减少；补充一瓶需明确点击“补充 · 2贝币”，最多6瓶，背包满、库存空、贝币不足或库存已满均不扣错资源。离开后自动合门。
6. 喝饮料有拿瓶、送到嘴边和倾斜瓶身动作；完成后消耗1瓶饮料，恢复30饮水和8饱食，推进2游戏分钟，同时生成1个空瓶。
7. 喝完后自动沿实际可走通道去接水点旁的垃圾桶。到达后伸手投瓶，瓶子沿短弧线落到桶口，完成才扣除空瓶。摇杆可接管，中断后空瓶仍保存在背包；以后走到垃圾桶旁也可继续丢。不会站在远处直接清掉物品。

## 存档和动作所有权

新增 `home_drinks` 库存字段，以及“饮料”“空饮料瓶”背包项；旧存档补默认值，库存计数越界会拒绝恢复。库存、背包与软货币变更在动作提交点各执行一次。暂停、菜单、角色更换和场景退出会冻结或清理临时姿态与道具；中断不会凭空丢失未消费的饮料。角色换装前主动取消生活动作，防止留下移动锁。

`home_fridge.gd` 负责冰箱内部和门，`home_routine.gd` 编排取饮料、喝、寻路与丢瓶，`home_gesture.gd` 处理手臂与瓶子道具；餐桌坐姿和吃东西扩展现有 `sofa_session.gd`，复用落脚 IK。`life_state.gd` 保存并校验饮料经济与垃圾资源。
