# 晴耕雨航 · 人物模型候选比对（2026-11-15）

## 一、先量清楚"现在这个人"是什么规格

实测 `assets/polyfork/swamp-child-base.glb`（headless 直接读资源）：

| 项 | 值 | 为什么重要 |
|---|---|---|
| 骨骼 | 22 根，Mixamo 命名（Hips / Spine / Spine1 / Spine2 / Neck / Head / LeftArm / LeftForeArm / LeftHand / LeftUpLeg / LeftLeg / LeftFoot / LeftToeBase… 左右对称） | 代码里 `_bone("Hips")`、`_bone("LeftArm")`、`_reach_arm()` 全都按这套名字找骨头，换模型必须保持同名或做 BoneMap |
| 动画 | 只有 3 条：`Idle` / `Walk` / `Run` | `player_controller.idle_clip/walk_clip/run_clip` 直接按名字播 |
| 网格 | 1 个 mesh、4922 三角面、顶点色（无贴图） | `_farmer_palette()` 是按顶点色改的，换带贴图的模型就不需要再调色 |
| 缩放 | `MALE_SCALE 1.72`、`FEMALE_MODEL choir-singer-base` + `1.60` | 换模型只需改这两个常量 + 重新量站高 |

结论：**只要新模型是"Mixamo 22 骨 + Idle/Walk/Run"就能零改代码替换**；骨架名不同就得走 Godot 4.4+ 的 `SkeletonProfileHumanoid` + BoneMap 重定向，并做 clip 名映射。

## 三、建议

1. **首选 Quaternius Universal Base Characters + UAL2**：CC0 无任何限制、男女双体型、20 发型可拼，UAL2 里正好有耕作/钓鱼动作，能和"晴耕雨航"的农活、垂钓对上。代价是要做一次重定向（Godot 4.4+ 自带 `SkeletonProfileHumanoid`）。
2. **求快就用 Ultimate Modular Men Pack**：自带 24 条动画，只要把 clip 改名成 `Idle/Walk/Run` 并核对骨骼名，一天能上。
3. **零风险方案**：先在 Polyfork 里找一套"岛民/农人"换皮，代码只改 `MALE_MODEL`/`MALE_SCALE`，不用碰重定向。

## 四、换人时的必改清单（三种方案通用）

1. `life_world.gd`：`MALE_MODEL` / `FEMALE_MODEL` / `MALE_SCALE` / `FEMALE_SCALE`；站高必须重测（现在是 1.203×1.72×0.667 ≈ 1.38 m），所有"上手高度"（哑铃 0.70~0.75 m、鱼竿握点、沙发坐高、床面）都跟着这个身高算的，换完要重新量。
2. `player_controller.gd`：`_bone()` 用到的 Hips / LeftArm / RightArm / LeftFoot / RightFoot；`_reach_arm()` 两骨 IK 依赖 UpperArm→ForeArm 的朝向。
3. 动画：`idle_clip / walk_clip / run_clip` 三条名；`bed_motion`、`exercise_session`、`home_gesture`、`home_routine` 都会直接 `animator.play(...)` 这三个。
4. 有了贴图就**不要**再跑 `_farmer_palette()`（它是顶点色重映射，贴图模型会被染坏）。
5. 换完必须重验：哑铃握姿（手心位置）、钓鱼握竿、沙发坐姿、床姿四套动作的骨骼对齐。

## 补充实测：Quaternius「Animated Base Character」到底能不能用（2026-11-15）

从 poly.pizza 直链拉到 `assets/cc0-quaternius/animated-base-character.glb`（`https://static.poly.pizza/0b65e14d-a349-44cc-836c-efdeb6933d48.glb`，**注意首次下载会被截断，必须校验 GLB 头里的 declared length**，完整文件 2,266,136 B）。

| 项 | 实测 |
|---|---|
| 骨架 | 53 骨，Rigify 命名（root / DEF-hips / DEF-spine.001-003 / DEF-neck / DEF-head / DEF-shoulder.L … 每只手 15 根手指骨） |
| 动画 | **45 条**：Idle / Idle_Talking / Idle_Torch / Jog_Fwd / Crouch_Idle / Driving / Fixing_Kneeling / Interact / Dance / Jump / Death01 … |
| 面数 | 13,744 tris（约等于现有农人的 2.8 倍） |
| 材质 | **无贴图、无顶点色**，单个 mesh 名 `Mannequin`，网格本身高 1.83 m |
| 画面 | 金身、无脸（没有眼/鼻/嘴），就是一个服装模特假人 |

结论：**不能直接换**。它是一套「给服装包用的素体」，画面里等于摆了具金色假人（`docs/shots/候补-Quaternius素体.png`）。要它变成人，必须再配 Quaternius 的 Modular Outfits / Ultimate Modular Men·Women 服装包（CC0，但只在 itch 页面点下载，poly.pizza 上没有）。所以手机上的 `farmer-304a43`（装机 1472）保持不动。
