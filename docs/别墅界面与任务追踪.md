# 别墅界面与任务追踪 · 0.9.2

右上角固定顺序为「任务｜背包｜设置」。原菜单功能保留在背包的「生活 · 制作 · 航行」入口：劳作、建房、生活、航行、集市、日历，以及存档、镜头等功能继续可用；设置仍保留操作布局等原有功能。

任务入口下不再常驻大任务卡和多行状态文字。只在存在未完成的追踪任务时显示紧凑条，展示任务名及采集数量/建房阶段，点击打开详情。条下提供暂停/继续、取消；取消仅清除追踪，不清掉已有任务进度和资源。任务完成后收起，无追踪时不占画面。航行入口会随追踪条的有无上移，别墅里不再显示船/瞬间出门按钮，回到一楼正门交互出门。

床上休息期间左下摇杆仍可显示，但不再控制人物，也不触发起床；躺下、安睡和起身过程中均忽略移动输入。只有点击「起床」才能主动离开床铺，夜间睡眠正常完成后仍会自动醒来。右下只保留「起床」，奔跑和建造隐藏；起身后原控制恢复。任务追踪、航行入口和地面光圈在休息期间收起。沙发休息同样减少无关控件，保留起身。

原地面光圈表示交互站位，并非任务进度。现在普通靠近不显示；主动点击交互、自动任务走向目标时才显示，到达执行动作时收起。右下交互文字继续提示当前可操作对象。

家具调整保持原分区与交互锚点：书房桌椅向前墙退让，放宽从客厅通往楼梯的路线；主卧床头柜向两侧和床头退让；二楼右侧座椅离开楼梯/通道附近。保留两层真实高度、连续楼梯、躺床和衣物恢复逻辑。

测试使用 headless 和 --test-mode，不打开预览、不读取正式存档。新增 test_home_hud.gd 覆盖入口顺序、闲时任务收起、进度、暂停继续取消、室内隐藏航行、休息期间摇杆不打断躺姿、按钮起床、控件恢复和右下起床动作；现有别墅、上下楼、钓鱼、镜头、碰撞及移动端布局继续回归。真机视觉需要实际打开确认，本轮安装不自动启动 App。
