# 上下床与斗篷连续动作

0.12.0 将临时放在床脚的衣物改为挂在床旁衣帽架，最新行为见 [衣帽架与完整室内视角](衣帽架与完整室内视角.md)。以下记录 0.11.0 初版动作。

使用现有角色骨骼与程序化动作编排，上下床不再只旋转人物后移到床边。仍沿用二楼主卧、床铺位置和休息数值。

## 上床

1. 双手伸向领口，脱下斗篷和帽子，折叠后拿在手里。
2. 真实走到床边，撑住床垫，抬腿坐到床沿，将衣物放在床脚角落。
3. 把腿移到床上，慢慢躺下，闭眼，进入休息。

整套过程约 4–5 秒，走到床边的时间随人物站位变化。恢复精力仍只在真正躺稳后累计。

## 起床

1. 睁眼，停止睡姿。
2. 撑起身体，转身坐到床沿。
3. 将双脚移到床外并落地，身体再离开床垫。
4. 撑起站稳，取回衣物，真实走离床沿。
5. 展开斗篷、披回肩上，整理领口并戴好帽子，恢复正常操作。

起床约 5–6 秒。手部配合衣物动作，斗篷使用原附件网格的临时副本表现拿取、折叠、放置和披回；不是布料物理模拟。女性现有模型没有独立斗篷时，仅处理实际佩戴的帽子，阶段文案相应调整。

角色没有原生眼睑骨骼，因此添加随头部移动的临时眼睑覆盖，表现闭眼和逐渐睁眼，完成动作后移除，不修改原始角色模型文件。

## 连续性与恢复

骨盆位置按床垫高度对齐，腿部使用两段 IK，脚落地前先移到床外，避免在床垫内下降。只有站立行走阶段启用真实人物移动；上下床摆姿时暂停普通移动碰撞，站稳后恢复。床上摇杆仍不会起床，只能点「起床」，夜间睡眠完成后自动进入起床序列。

提前点击起床会按当前阶段取消或衔接起身，不从半躺姿突然传送到站立点；起床过程中重复点击不重置动作。暂停、后台和菜单打开时冻结动作和恢复计时。退出、重置、换角色等中断会移除临时衣物/眼睑，恢复原始附件可见状态、骨骼姿态和碰撞。

床边两段行走通过真实碰撞，宠物根据这段自动移动的实际速度让路；受阻时安全停止，恢复可操作状态。存档仍只保存安全床边位置，不保存半空姿态，也不消耗衣物或资源。

## 实现与验证

- `bed_motion.gd`：阶段时序、骨盆与腿 IK、手部动作、临时衣物和眼睑。
- `player_controller.gd`：床铺动作入口、暂停和清理。
- `bed_session.gd`：阶段提示、恢复与夜间睡眠。
- `companion.gd`：床边自动走动时让路。
- `test_bed_sequence.gd`：两套阶段顺序、连续位移、落脚、暂停、衣物恢复、女性角色、重复起床、提前中断、资源不变与场景退出清理。

使用六个实际骨骼快照进行后台离线姿态核对，包含脱衣、坐床沿、躺下、起身、落脚和披回衣物。离线图不代表 Godot 真机渲染或动画帧率；本轮不打开预览、不自动启动手机游戏。
