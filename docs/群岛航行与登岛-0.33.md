# 群岛航行与登岛

## 操作

1. 从主岛码头上船，坐稳取桨后，用摇杆驶向周围四座岛。小地图会切换为群岛海图，显示岛名和岸边停船标记。
2. 靠近可登陆的海岸，右下主按钮显示「登岛」。点击后进入经过检查的岸上落脚点，船停在附近水面。
3. 岛上可以行走、观察动物；右下船形辅助按钮和上方入口均显示「返回船上」，不必徒步走回海滩。回船不扣物资，不因食水不足而把玩家困在岛上。
4. 回船后可继续驾驶，或点击「返航主岛」。自动航行会绕开岛屿，最后在主岛码头减速靠岸；推摇杆可随时接管，按钮也可取消返航。

四座岛均已从远景外观接入实际玩法：双丘林岛、弯月沙湾、礁岩小岛、长岬林岛。海域半径扩大至600米，保持有限的安全边界，海面视觉继续延伸至远方。每岛预先检查48个岸段的陆地落脚点、水深和船身空间；船仍不能直接开上陆地。登岛使用区域转移，不包含跳板步行动画。

## 碰撞与画面

岛屿使用真实三角网格地形碰撞及地面高度。访问岛屿时，原先合批的植被切换为具有树根、树干、枝条与镜头遮挡处理的近景模型，岩石和陆地动物也有碰撞；离岛后恢复合批显示。动物在近处活动，宠物跟随登岛。登岛和回船会清除旧摇杆输入，防止转移后沿旧方向移动。

小地图在船上显示群岛海图，上岸后聚焦当前岛屿；场景标题显示岛名。船尾浪花的渲染范围同步跟随船只，驶离主岛后不会因为旧边界而消失。

## 存档与返回

记录当前访问岛屿、岸上落脚点、停船坐标与船头朝向。上岸行走位置正常保存；航行中保存采用最近安全岸段，重进后从岸上恢复，船仍在该岸段，能够继续点击返回船上。没有访问记录的旧存档自动兼容。

停船数据在恢复前验证坐标、岛屿标识和数值有效性。无效停船位置会安全回到主岛码头。返航主岛、跨城旅行或重置游戏后清除旧岸段记录，避免把船留在错误位置。远岛探索期间，主岛生产任务提示先返航，避免人物沿旧主岛路线走入海中。
