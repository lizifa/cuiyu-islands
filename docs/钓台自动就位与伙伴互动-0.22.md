# 钓台自动就位、鱼竿受力与伙伴互动（0.22）

## 一键就位

扩建后的钓台原来仍只有约 1.5 米触发范围，且码头的优先分支会覆盖钓台东侧的提示。现在以钓台实际区域判断交互，钓台区域优先展示“钓台垂钓”，实际登船站位仍展示船只操作。

点击后使用实体移动前往固定安全站位，平滑转向海面，再移到凳子垂钓。钓台使用局部 0.15 米网格，避免通用 0.6 米网格把凳子、桶和护栏之间的可行通道误判为堵死；人物不会直接穿过装备传送到钓位。摇杆、暂停及取消保留原规则。只靠近而未点击时，不强制转身或改变镜头。

## 鱼的大小与鱼竿

普通大鱼概率 10%，撒饵后 20%，好鱼竿额外增加 3 个百分点，最高 23%；替换原先撒饵时 55%～65% 的高概率。每竿分别决定大小类别与类别内的受力大小，普通鱼仍为主，大鱼不会因为连续按按钮重复抽取。

收线弯曲由鱼的大小、当前张力和轻微挣扎共同驱动。大鱼在相同张力下弯得更明显，满负载最大弯曲提高，松线后卸力回弹；保持竿身总长和鱼线连接，不改变断线、奖励和抄网结算规则。鱼的显示尺寸也在小鱼/大鱼类别内轻微变化。

## 柔和跳跃

原先前后腿同时收起，腾空曲线边界速度突变，打断时高度直接归零。改为蓄力、起跳、前后腿错峰收展、落地缓冲；身体高度和关节幅度逐帧平滑，主人离开时短暂柔和落回并跟上。关键交互、乘船和换场仍会清理姿势，暂停时冻结动作。跳跃是轻量骨骼程序动画，仍需真机体验来判断最终观感。

## 和附近动物玩

宠物自由活动时，有机会选择主人附近约 3.2 米、宠物附近约 3.5 米内的陆地动物，优先考虑最近且有安全接近位置的对象。不会选择海洋、飞行生物或船。双方先朝向彼此，再以小范围侧移/绕行回应，不播放追咬或战斗，也不主动把远处动物拉到主人身边。

宠物与动物始终保留碰撞；目标、完整占地、道路和地形安全检查照常生效。空间不足就等待或恢复普通活动，不强行穿过主人或家具。主人开始走动、离远、劳作、抚摸、乘船或目标消失时，解除伙伴占用并恢复跟随，野生动物恢复原巡游。暂停同时冻结双方。

## 验证

新增 `test_fishing_access_size.gd`：从四个可行方向点击垂钓、实际走到站位并面向海面、登船位置优先级、概率和同张力下大小鱼的差异/卸力。新增 `test_pet_social_hop.gd`：跳跃起落高度连续、前后腿错峰、打断缓冲、双方真实响应、碰撞、暂停与主人离开后的解除和跟随。

所有脚本检查均使用 `--test-mode`，不操作正式存档；不打开编辑器窗口、预览或手机游戏。后台离线画面用于复核关键帧，不能代替真机动画、触感和运行温度验收。


完整回归曾出现一次自动搭建庇护所中断，带诊断复跑未重现；针对劳作期间仍可能开始闲逛的路径，补上劳作高优先级抑制，并重跑自动任务、宠物随机活动、伙伴互动、交互站位、抚摸重置与实体碰撞检查。该记录区分观察到的失败与尚未确定的直接原因。

最终验证：54 组测试累计 2728 项检查通过（包括修正后的相关复测），`git diff --check` 通过；后台离线检查跳跃蓄力、腾空、落地与回稳关键帧。
