# 上下床接触与二楼镜头（0.19）

本版针对录屏中的床沿腿部下陷、床前/脱斗篷远景，以及上楼结束时的镜头遮挡风险。

## 床与动作接触

原床垫偏高，而坐床沿的脚点放得过远，部分目标超出了人物腿长。调整床的垂直比例，保留平面摆放和宽长；高度修正烘焙到独立网格，再生成一致的碰撞体，不对物理身体施加非均匀缩放。床垫高度通过实际网格三角面测量，坐姿骨盆和躺姿留出身体厚度。

区分床沿落脚点与站立落脚点；脱穿鞋时脚点保持可达，上床按次序抬脚，下床先把脚移到床沿地面，再借力起身和迈开。取消原先横移后集中下降的骨盆轨迹。所有阶段交接从上一阶段的世界空间骨骼姿态短暂融合，不直接重置为标准站姿；穿鞋后的起身与离床行走同样连续衔接。鞋子的落点同步调整，暂停、提前起床、性别切换及清理保持原逻辑。

## 卧室镜头

衣帽架前和脱穿斗篷使用斜前方中近景；坐床沿、脱鞋、抬脚、起身使用床侧略高机位，保留膝盖、脚和床沿；躺下休息稍微放宽展示整张床。仅在动作组变化时更新构图，结束/取消释放镜头并恢复原视角，不逐阶段甩镜头。

## 楼梯到室内

楼梯结束后保留约 0.65 秒的平台后侧镜头，再用约 0.95 秒混合回室内远景，同时由较收敛的楼梯视野平滑恢复日常视野。相机扫掠半径按近裁剪面及最大室内视野计算，包含近裁剪面的四个角，防止中心点安全但画面边缘进入浅色墙体或顶板。

用户提供的这段录像没有包含上楼白屏瞬间；本次修复针对已定位的镜头交接和近裁剪遮挡风险，尚不能代替白屏发生点的真机复核。
