# 海上交互与镜头 · 0.6.0

## 岸钓

码头钓台使用3.6米分节海竿，浮漂距钓位约20米；甩竿有抛物线，收线时交替提竿与下压摇轮，竿尖按张力弯曲，左手跟随摇柄。镜头平滑拉远追踪浮漂，落鱼时拉近，结束后恢复原取景。原有张力玩法、资源成本、奖励和触感设置沿用。

## 航行与靠岸

登船后点击右上“一键自动靠岸”，船沿可通行水域返航，从码头外侧直线进入泊位，停稳后下船。途中拨动摇杆或点击取消可接管；持续受阻会暂停提示，不会穿过障碍或直接传送。

玩家船使用完整船体碰撞，环境小船也有实体船体；近距离环境船暂停沿装饰路线移动，避免主动侵入玩家船。环境船仍属于装饰航线，没有完整交通避让系统。既有航行范围保留，远景扩大不意味着开放无限航行。

## 镜头、海面与太阳

镜头位置受地面高度和遮挡约束，抬头看天空时相机仍留在地表上方。菜单“看太阳”在户外白天转向当前太阳；太阳位置随时刻变化，夜间和室内隐藏。

近海按水深显示浅滩与深水，远海延伸到相机视距之外并融入天际线。新增四座远岛剪影，仅作风景，不能登陆。没有新增海底探索玩法。

## 树根与旧存档

树木低处根部独立计算碰撞范围，人物增加平底脚部碰撞，自动任务查询同步采用脚部净空。小于10厘米的平坦台阶可跨越，树根不会被当作小台阶爬过。旧存档若恢复在树根内，首次进入岛屿时移到附近安全地面，保留进度和物资。

## 0.6.1 视频反馈修正

玩家和环境船共用boat_hull.gd，从模型hull网格取得水平凸轮廓，按各自缩放和视觉高度生成凸棱柱碰撞体，排除船桨。船头船尾的空水面不再被长方盒覆盖；仍使用简化凸包，不模拟船舱凹槽或水动力。转向受阻时二分查找可用角度，保留沿障碍滑动。环境船仍不可推动，4.5米范围仅暂停其航线，自动返航安全范围独立保留。

航行时手动上仰保持船在画面内；菜单“看太阳”临时进入观景，下次手动拖动恢复航行取景。
