# 镜头观察与小地图 · 0.7.3

## 移动和观察分开

默认情况下，单指或鼠标左键从场景空白处拖动，平移观察位置，保持镜头方向与俯角。左手摇杆仍能独立移动人物或船，右手观察不会因环绕旋转而改变移动方向。6像素以内的抖动忽略；拖动距离按视距、视场角和视口高度换算，使用随时间指数平滑。

按住时保留观察位置，松手约0.55秒后平滑回到人物。小地图旁在观察时出现“回到人物”，可立即结束观察并平滑回中；恢复正常跟随后隐藏。观察半径在岛上18米、船上26米、室内4米，并受场景关注范围约束。人物本身不会因镜头观察移动或获得资源。

菜单“旋转视角”保留原来的环绕与上下查看；旋转时菜单入口显示“平移观察”。“看太阳”进入明确的天空观察模式。点击“回到人物”退出旋转/看太阳，恢复进入前的跟随角度。菜单“视角归位”仍可恢复初始方向。相机位置继续经过地面高度与遮挡处理。

## 控制权和场景切换

摇杆与观察手势各自绑定触点，释放一个不会释放另一个；模拟鼠标事件不重复处理原生触摸。操作按钮、小地图、菜单和设置区域不会启动场景手势，菜单打开时也不能从空白背景开始观察；释放到UI上仍会正确结束观察。

显式交互的推荐取景会清除已有临时观察偏移，再平滑构图；如果用户在就位过程中主动观察，仍尊重手动接管。钓鱼阶段不会覆盖这次手动选择。切换地点、登船或下船时清除旧观察偏移，避免把上一场景的关注点带入新场景。自动回中不改变资源、任务或存档进度，正常游戏时间沿用既有规则。

## 小地图

白色人物箭头继续表示人物位置和朝向；细线框显示当前镜头投向地面的近似观察范围，观察时另用青色标记表示镜头关注点。范围来自视口四角射线与人物所在高度平面的投影，并裁切在地图内部；这是导航示意，不是逐三角面的可见性计算。朝天空观察时不绘制无效地面框。

岸上保持原27米半径海图，出海扩大到72米半径，覆盖可航行海域；靠岸后恢复原尺度。室内按原房间地图显示。地图仍按约8Hz更新，土地底图只在地点、楼层或尺度变化时重建。
