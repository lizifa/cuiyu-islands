# 碰撞与劳作间距

## 原因

森林树木缩放不同，碰撞却统一为0.22米半径；原有树木使用固定方盒。松树低处枝叶比树干宽，人物站在碰撞允许的位置仍会进入可见模型。散落岩石与采集物缺少实体碰撞。别墅家具使用手工指定的占地盒，和旋转、缩放后的实际模型有偏差，餐椅也没有碰撞。自动任务只判断最大交互范围，缺少动作所需的最小停靠距离。

## 修复

树木按模型低处顶点计算包络圆柱，继承模型旋转、缩放；将低枝叶计入包络，人物不能走进树干或低枝。岩石、帐篷、箱子和别墅家具、椅子使用网格凸包；采集块、篝火与储水桶增加实体碰撞。凸包作为简化实体，会封闭座椅、浴缸等局部凹槽，当前不支持坐进或跨入家具。

人物胶囊半径从0.28提升到0.4米，自动寻路查询半径为0.48米。树木与采集点声明最小操作距离，寻路目标选在最小距离外侧，并预留到达误差；开始和完成劳作都校验距离。树林最大交互范围适当扩大，保证宽松树仍能操作。劳作只驱动上身骨骼，不向目标中心移动身体。

室内真实餐椅阻挡后，一楼行走测试改走餐厅西侧通道，验证到厨房、楼梯、卧室与大门的路线仍可达。保留原有进度和资源规则，不重置游戏。

## 验证范围

新增实际角色移动抵住树木、石材和纤维采集物、逐帧检查伐木/拾石/采纤维的操作间距，并检查家具实体碰撞；另回归建房、修船登船、宠物动作和别墅通行。使用headless物理运行检查，不自动打开游戏或预览。视觉遮挡与身体穿入实体分别处理；树冠透明属于遮挡处理，不替代实体碰撞。环境小动物仍使用既有装饰路径，本次不实现动物导航系统。

## 0.6.0 根部与船体补充

树根使用低处顶点独立包络，人物增加平底脚部碰撞，自动任务同步检查根部净空。只允许跨越低于10厘米的平坦台阶，保留别墅门前通行；树根八方向阻挡和旧档根部脱困检查通过。航行改为实体船体物理移动，环境船也有船体碰撞。一键靠岸经过外侧候船点沿直线驶入，避免斜切码头角。详见《海上交互与镜头》。

## 0.6.2 树木头肩净空与分段碰撞

量测发现男性模型帽顶约2.27米，原身体胶囊只有1.7米，披肩也超过0.4米半径。现在保留室内通行使用的身体碰撞，另对树木增加半径0.68米、高2.5米的头肩净空扫掠。移动前限制树木方向的位移，物理滑动后再次核对实际位移；受阻时保留沿树侧滑开的分量，检测形状缓存复用。

树木缓存原始木质三角面，按实际世界高度裁切为多段凸棱柱；包括跨越采样高度的三角边，不再只按局部顶点高度估半径。现有三种Polyfork树的绿色叶面与棕色/米色树皮按顶点色分开：树根、树干和木质枝条阻挡，树叶仅作视觉遮挡。该分类针对当前素材，换素材需重新验证颜色语义。

树叶与树皮拆成独立材质表面，靠近人物或遮住镜头时只淡化树叶，树皮仍不透明。森林树木继续批量绘制，近处切回独立绘制；营地三棵树也使用同样规则。林木布置为营地到码头留出净空走廊，避免新增头肩净空后堵住唯一通路。树总数保持68棵。

全部砍树点以实际木质碰撞包络加头肩和动作余量生成站位，自动寻路增加树木专用高净空查询；普通家具与建筑仍沿用原通行尺寸。旧档脱困结合根部距离及实际分段形状检查，避免因高处枝条包络过大而把正常门前位置传回营地。

新增TREE CLEARANCE 130项：三种树、两种缩放、八个方向连续移动时逐帧检查头肩不与木质碰撞体重叠；追加6组实际挥斧动作的头部、躯干与手臂关节净空检查，并验证68个砍树点的站位规则、近处树叶淡化和树皮保持不透明。另回归原有自动劳作、登船、别墅通行、船体和旧档恢复。headless检查不替代真机画面及长时间发热测量。
