# 居家休息与移动端性能 · iOS 0.4.2

## 沙发与电视

一楼沙发旁交互后，人物移动到沙发坐垫位置，降低髋部并弯曲大腿、小腿，朝向电视。以模型实际坐垫顶面约1.012米对齐髋部目标1.13米，男女模型按骨架缩放计算偏移。当前只提供坐姿，未实现躺姿。休息期间每个真实秒恢复1/6精力与健康，即120秒各恢复20；游戏时间继续推进，食水按休息规则消耗。暂停、打开菜单或失焦不恢复，测量模式不恢复，不在点击时瞬间加满。

底部休息面板提供开关电视与起身；电视播放轻量程序化海景画面，不联网、不解码视频、没有声音。摇杆输入自动起身，恢复碰撞和站立动画。离开别墅、换楼层、换人物时清理坐姿。存档保存沙发外安全站立位置，重进游戏不会卡进家具；电视当前仅在本次运行中保留开关状态。

## 省电设置

设置新增「省电模式 · 30帧（关闭为60帧）」，独立保存在performance.cfg，不影响生存存档。移动端默认省电，3D渲染比例0.8，UI保持原生分辨率，单级方向光阴影距离28米；关闭省电恢复60帧、完整3D分辨率和两级阴影。菜单/暂停上限15帧，失焦上限5帧。iOS脚本默认构建Release，--debug可切回调试版。

省电模式将森林65棵树按16米网格及网格资源分组为MultiMesh；保持树木原有缩放、位置、顶点色和实体碰撞。遮挡人物的树从批次隐藏，临时切回独立透明模型；退出遮挡或关闭省电时还原，避免重复绘制。人物静止落地且位置未变时跳过重复的移动碰撞及地面遍历。

CPU权重是所有线程Running样本的累计，不能等同GPU时间或温度；引擎process监视器也不等同系统CPU计时。树木批次后绘制提交比省电初版少约11.2%，CPU相近；不能声称批次进一步降低了CPU。相对初始Release，最终CPU样本约少11.5%，但场景时间推进/测量冻结、初始热状态与冷却时间未严格控制，不构成严谨A/B因果证明。最终Nominal不能证明所有使用时长和场景都不会发烫。

未采得摄氏温度、电池消耗或可单独量化的GPU帧时间；未做长时热稳定测试。保留上述限制，不将桌面headless成绩当作手机温度、帧率或动作视觉验收。

初始源码微基准：sync8.34微秒/次、遮挡13.48微秒/次、context29.35微秒/次、overlay1.71微秒/次。这些单项不足以独立解释发热。Instruments初始记录中渲染入口包含约11.07秒CPU样本、脚本入口约7.40秒、阴影约2.48秒、天空辐射更新约0.74秒；包含时间有重叠，不能相加。

证据摘要保存在忽略目录build/evidence/ios-042。--profile导出仅临时加入perf_probe特性，冻结游戏时间、禁用存档写入，90秒输出报告后停止探针并降低帧率；iOS不保证自行退出，由外部采样控制结束进程。首轮命令行参数未取得引擎帧率数据，后续改用导出特性并核对设备标记文件，正常交付PCK已验证不含perf_probe特性。
