# 钓鱼落水波纹（0.34 / build89）

## 原因与修复

原 `_update_visual()` 前面限制波纹在等待等阶段显示，后面又用 `stage not in [ready, charging]` 覆盖，导致点击甩竿后、浮漂还在空中就显示水圈。旧网格每秒突然重置大小，也容易形成机械的大圆圈。

现在波纹统一由落水状态控制：

- 刚进入钓位、蓄力、甩竿飞行时，波纹完全隐藏。
- 第一/第三人称共用抛投轨迹和时间常量：0.25秒准备、0.95秒飞行。浮漂到达终点转入等待时，只登记一次落水。
- 落水后产生两层逐渐扩散、淡出的细波纹，约1.6秒后只保留浮漂附近轻微水纹，不再周期性把大圈重播。
- 波纹贴着海面，使用与海水相同的波高函数；位置跟随实际浮漂的X/Z，不是提前钉在预计落点。
- 咬钩不重新触发抛投波纹；收线时水纹随浮漂移动。提早收竿、重新蓄力、收纳和结果阶段清除旧水纹。暂停冻结波纹扩散进度。

本次没有增加新的钓鱼收益，也没有改动鱼类概率、抄网或人物腿部动作。
