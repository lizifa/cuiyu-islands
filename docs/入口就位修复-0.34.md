# 进门与上船就位修复（0.34 / build86）

## 行为变化

进别墅和上船使用有效区域，而不强制到达预设脚下坐标。门口已经可进入时直接进入；从较远处自动接近时，一旦进入有效区域就结束路线。门口区域限定在正门外侧、距入口1.8米、左右1.3米内，并检查当前位置通行性；附近的墙体、树木等碰撞不会被移除。

上船在可通行的码头上船区域内直接进入准备动作；不再先面朝船转一遍，再强制转成划桨坐姿。上船保留当前朝向，用0.75秒按最短角度平滑转向船尾，和坐下、取桨过程同步。传统双桨划船最终仍然面朝船尾。

自动回家/自动上船同样提前结束接近路线，不再额外执行原地朝向阶段。入口接近路线跳过起点的网格吸附点，防止第一步向后纠正；采集、钓鱼、用餐等需要精确站位的交互保持原来的规则。

进入室内时清理原来的移动输入和速度，方向朝室内。没有新增相机绕行、自动放大或强制镜头旋转。远岛回船保留既有停船朝向。
