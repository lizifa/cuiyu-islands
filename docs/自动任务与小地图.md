# 自动任务与小地图 · 0.3.0

## 玩家交互

右上“任务”打开任务面板，选择执行：采木12、拾石8、采纤维8、篝火、庇护所、建造自己的家或修船。收起任务面板后，人物会自行寻路到目标旁，播放工具/手臂劳作动作，完成后才提交资源或建筑变化。右上显示当前前往/动手状态及数量/阶段进度。任务面板显示材料需求、当前背包和里程碑补助，完成里程碑后手动领取。

建房按地基、墙体、屋顶、门与床依次检查；只收集当前阶段缺少的材料，再返回可施工的位置。材料、能量、饱食、饮水、游戏时间均调用原 State 规则，无免费材料或货币。房屋各阶段在场景中实际显示。篝火、庇护所和船分别前往对应位置施工。

只同时执行一个任务。可以暂停、继续或取消；推动摇杆/键盘或按奔跑会立即手动接管。打开任务、设置、背包、地图等面板或失焦会冻结执行；关闭后恢复。手动采集/施工/交互会终止自动执行。精力低、食水不足、背包满、不可达/卡住、保存失败时暂停并说明原因。四季按实际日出/日落时间暂停新动作；玩家可明确选择夜间继续。自动修船不会自动登船、航行、消费、交易或接取订单。

## 导航与动作

`auto_tasks.gd` 将决定目标、A* 寻路、接近交互点、动手和提交结果分开。按 0.6 米网格采样现有地形，排除水域、陡坡、树干和建筑，使用胶囊体查询保证与人物碰撞一致。地形碰撞网格仅在采样查询中排除，人物真实移动仍受地形碰撞。施工改变障碍后重建缓存；路线终点位于交互范围内的可站立位置。沿路径驾驶现有 CharacterBody3D，不瞬移；停滞会暂停，避免不停撞墙。

劳作使用现有骨骼的程序化挥臂，伐木/拾石/施工附加简易斧或锤，采纤维用徒手动作；完成约 1.8 秒可见动作后，再经原有规则提交。途中取消不发资源。当前资源沿用原可重复采集规则，未实现砍倒整棵树及树木重生。

任务是会话内安排；每个有效劳动结果和施工阶段照常保存，重启不会自动继续或离线产出，需重新选择任务。手动调整人物位置后可以显式继续受阻的任务。

生存状态条放在地图下方；右上任务替代原来左侧目标条。正常游戏只显示独立圆形辅助按钮，没有围住它们的大框；自定义布局编辑中仍显示整组范围，用于整块拖动。

## 0.3.1 每日清单与登船修正

每日（游戏日）固定任务为采木12、拾石8、采纤维8。手动与自动、建设补材中的真实成功采集都累计当天进度，花掉材料不减已完成量。完成的项立即从清单移除，全部完成只显示收工提示。每天00:00按游戏日刷新；没有未完成惩罚，也不会自动接着做下一天任务。显式跨天继续后重新按新一天累计。

独立 daily 字段随存档保存；旧存档按其当前游戏日新增空进度，不动背包、人物、建筑和货币。主档/备份恢复仍使用原校验路径。篝火、庇护所、木屋和船是建设目标，建好后从列表移除，不在次日重复出现；有木屋后不再提示搭临时庇护。

原来的修船任务只修理，不等同于上船。现在修好船后清除修船项，显示独立的“前往码头并自动上船”：预查船、天气和食水，走至码头尽头1.2米范围，再真正进入驾驶状态。上船仍停留在本岛，不自动消费或去镇上。手动码头交互与 board_boat 共用3米范围，在码头优先显示修船/上船，不被其他交互抢占。夜间登船不再套用日落劳作暂停规则。上船后摇杆划船，回码头靠岸。

测试覆盖每日完成移除、材料花掉不重开、磁盘重载、旧档迁移、次日刷新、跨天暂停、真实码头自动登船、手动上船、夜间上船和风浪/缺食水预查。仅headless，未自动打开预览或启动手机游戏；实际手机画面和触摸体验仍待实测。

## 0.3.2 船只状态与准备入口

排查时读取手机已有存档的非身份字段，看到未建小船、精力0；同时只读取了已经在前台的游戏截图，没有启动游戏或桌面预览。画面里的完整船模型与角色实际登船范围、未修复状态之间缺少提示，易被理解成靠近可见船便可直接驾驶。

右上增加固定“我的船·未修复 / 上船·前往码头 / 上船·已到码头 / 靠岸”入口。已修好的船点击一次即可直接上船或自动走到码头；没有额外确认。未修好时显示材料、精力、码头距离，并确认可选的正常短休、补水和使用背包食物，再自动收集缺材修船。短休仍每次2小时恢复20精力，食物和补水使用原成本；没有赠送精力、材料或直接修改船只进度。若没有食物、天黑或风浪等仍给出相应原因与后续操作。

任务中的修船入口也打开同一个准备流程。未修船只倾斜并放维修木板，近距离显示“待修复 / 已修好”标签；船模型可见不再等同于已解锁驾驶。精力等状态名称固定单行，避免手机上两字被挤成竖排。

新增从精力0、缺材料开始，按原时间与资源成本休息补给、真实采材修船，再一键寻路登船及码头直接上船的集成检查。更新继续保留用户存档，不替用户执行休息、花材料或重置进度。
