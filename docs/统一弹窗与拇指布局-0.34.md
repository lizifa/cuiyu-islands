# 统一弹窗与右下拇指布局（0.34 / build90）

## 弹窗

背包、功能菜单、任务、生活/制造/航行等操作页、设置、大地图、帮助、素材鸣谢及出行/重置确认框采用相同的居中窗口尺寸：安全区域内最大860×580，空间不足时同步缩小，四周至少留16逻辑像素。

每个窗口顶部右侧使用统一的X图标，触摸区域48×48。标题栏固定，长内容在内部纵向滚动；不再把关闭按钮放在滚动列表或底部。帮助、鸣谢没有额外“确定/关闭”页脚；重置、出行等真正的确认操作保留明确的确认按钮，顶部X仅取消，不会执行动作。

确认、帮助和鸣谢改用共同的游戏内弹窗容器，避免系统原生窗口的尺寸、关闭栏和底部按钮不同。支持Escape取消，帮助关闭后恢复打开前的暂停状态。地图可以使用顶部X，也保留点击地图还原的操作。

开局选人属于完整页面，保留完整人物预览布局，底部返回改为右上X。钓鱼状态条、休息/用餐/冰箱等场景操作HUD不属于弹窗，保留其紧凑布局，避免覆盖场景。

## 参考图的右下操作区

主交互按钮位于右下；奔跑/加速在其上方，建造/靠岸位于左上，形成弧形。船上额外的停船、返航小按钮分布在左侧，五个触摸区域互不重叠。主按钮距安全区域右侧约47、底部约67逻辑像素，较旧布局留出更多边距。

图标更突出，默认圆底变淡并去掉常驻描边，按下才显示轻微轮廓。保留短文字以说明当前动作。右侧操作区采用统一固定弧形，旧文件内的右侧自定义位置不再覆盖新版排列；独立的左摇杆偏好和原配置文件保留。

## 验证

统一弹窗125、按钮弧形92、船技47、上船6、宠物/重置47、重置镜头76、居家HUD17、任务红点10、钓鱼HUD173项检查通过。

窗口及按钮覆盖1560×720、1280×720、960×540、1600×960四种尺寸，包含非对称安全区。检查窗口尺寸一致、边界、顶部关闭热区、取消重置不改变存档、帮助恢复暂停、Escape取消、无底部重复关闭、五按钮互不重叠及安全留白。

钓鱼HUD测试退出时有两个音频资源释放警告，verbose定位为AudioStreamWAV和AudioStreamPlaybackWAV，不是弹窗对象；逻辑断言全部通过。未自动启动游戏，未进行真机视觉/手感验收。
