# 钓台扩建、受力鱼竿与开局界面（0.20）

## 桥与钓台

岸边木桥宽度由 2 米增至 3.2 米，向西扩展，保持东侧船位与登船位置。钓台由 5×4 米增至 6×5 米，栏杆、立柱、木板接缝、实体碰撞与可行走边界同步调整。桥面在钓台连接处拆为不重叠的三段，避免共面地板重复绘制造成闪烁。钓鱼开口、凳子和既有装备仍可使用。

## 海竿受力

八段竿身按张力和鱼的拉扯方向形成连续受力曲线，各段长度保持不变；提竿、收线、大鱼拉扯、抄鱼到卸力分别调整负载，短暂平滑过渡。竿尖弯曲幅度随张力增加，松线后回弹，鱼线始终从实际竿尖出发。此处为轻量程序动画，不是弹性材料有限元模拟；捕鱼收益、断线阈值和触感逻辑保持原规则。

## 选人与设置

横屏两栏：左侧角色与伙伴展示台，支持拖动旋转；右侧直接点选男女角色及狗、猫、兔子或独自出发。名字、伙伴名字和选择内容可滚动，确认与返回固定在底部。选中状态同步模型，“独自启程”禁用宠物名字；修改既有角色保留房屋、背包及任务进度。修正标题换行引发左栏最小高度膨胀的问题。

设置移除“自定义布局”入口。保留旧布局文件的读取与内部兼容逻辑，不删除玩家存档或重置现有按钮位置。

## 宠物步态

狗、猫、兔子素材已有骨骼行走和奔跑动画；跟随路径短暂停顿时频繁切回待机，且播放速度与实际移动不一致，会出现滑行。现在以碰撞处理后的水平位移推进动画周期：慢速走路、快速奔跑；短暂停顿保留当前脚步，停止后回到待机，传送或乘船不推进走路。暂停时冻结骨骼，保留跟随、避让和实体碰撞逻辑。

## 验证范围

新增 `tests/test_scene_refresh.gd`，覆盖 1280×592、1280×720、1024×768 下确认按钮可见、卡片选择、伙伴名字状态、设置入口、扩建通行、张力弯曲且不伸长、三种宠物真实脚部骨骼变化、暂停与站立恢复。所有检查带 `--test-mode`，不改正式存档。

后台离线导出检查桥面接合、船位和受力竿曲线；离线图用于检查几何与构图，不能替代手机实际渲染、触感和帧率验收。
