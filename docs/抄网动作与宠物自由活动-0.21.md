# 抄网动作与宠物自由活动（0.21）

## 抄网为什么看不出来

原来已有 landing 阶段，但仅约 1.8 秒，左手目标基本固定，主要靠网柄缩放及鱼的位置插值表示捞鱼；镜头距离仍为 16 米，动作不易辨认。鱼模型原点位于底部，直接将根节点放到网兜位置也会令鱼身浮在网口上。

## 新的起鱼动作

使用共享的 `fishing_landing.gd` 时间线：拿网约 0.55 秒，向水面下探至 1.35 秒，再从鱼腹下方兜住鱼，1.85 秒后提起，3.4 秒完成。左手控制网柄，网口朝上、网袋向下；人物屈膝探身，脚部 IK 保持着地，右手继续持竿。伸缩网柄连接实际左手与网口，网口扩大至约 1 米、网袋深约 0.65 米，半透明网袋保留鱼身可见。

收线目标实际接近岸边起鱼位置，不再在阶段切换时从远处直接跳到网口。鱼被兜住后按实际模型包围盒中心跟随网袋，完成提起后才结算一次；成功结果继续展示鱼在网中，取消/再甩竿时清理。普通鱼继续自动进入起鱼动作，大鱼仍需点“抄网”。

自动推荐镜头在起鱼时平滑转到斜侧方，距离约 7 米，焦点稍抬高，兼顾人物、网口及顶部 HUD；玩家手动改过镜头后不强行接管，取消垂钓恢复之前的视角。

## 宠物活动与跟随优先级

人物静止约 1.4 秒后，伙伴在主人约 3.2 米范围内随机选择停留、慢走、短跑或短跳，每次方向、目标与持续时间随机，不播放固定动作串。狗、猫、兔子继续使用已有 Walk/Run 骨骼动画；没有现成跳跃片段，短跳通过腿部收展与身体高度共同表现，实体碰撞始终保留。坐沙发、躺床休息、钓鱼时也可在安全区域活动；上下床过渡、抚摸、拿饮料等关键交互保留原有避让，船上不会跳跑。

主人开始移动或间距超过约 4.2 米时，中断自由活动并优先跟随；闲逛路线保留可返回的路点，并在有安全直线通路时缩短返回路线，之后继续沿主人实际走过的路径追上。走得过远时沿用原有安全恢复机制，换楼层沿用楼梯结束后的伙伴恢复。设置、暂停和失焦时停止活动计时及动作。

随机目标沿途检查地面、坡差、宠物完整占地边缘和实体碰撞；跳跃前检查头顶空间。不会通过自由活动跨入海面、越过护栏、穿过家具，狭窄地段找不到安全动作时保持等待。

## 验证

新增 `test_net_landing.gd`：男女角色手与网柄贴合、手臂明显下探/抬起、网口入水再提起、鱼留在网袋、推荐镜头及单次结算。新增 `test_pet_activity.gd`：三种伙伴随机动作多样性、真实移动和腾空、安全半径、设置暂停、主人离开后中断玩耍并追上、抚摸与乘船抑制活动。

52 组测试共 2700 项检查通过，修改网袋与鱼身中心后重新检查起鱼、完整垂钓、装备和横屏 HUD；其余包含登船、靠岸、居家生活、上下床和楼梯镜头回归。全部使用 `--test-mode`，未操作正式存档。后台离线图检查动作关键帧的几何与构图；尚未启动手机做实际动画观感、触感、帧率或温度验收。
