# 别墅景观与水泥路 · 0.8.0

使用 Polyfork 的 Broad Canopy Shade Tree 作为舒展的乔木，Ornamental Front-Yard Tree 作为庭院景观树；保留白桦、幼松作为林下层次。统一绿色低多边形风格，不混入不同季节的红黄树冠。

岛上固定生成 37 棵景观/森林树（含 3 棵北侧庭院树），另有 3 棵营地采集树。森林树干至少相隔 2.7 米，并排除别墅、营地、码头通道以及水泥路外扩 2.8 米范围；通过树种、旋转和 0.62–0.85 倍尺度形成层次。原营地东南侧的树移至西侧，采集交互点跟随移动。庭院树也可正常采木。

别墅正面是长 13 米、宽 4 米的浅灰水泥步道，覆盖世界 X=3–16、Z=1.8–5.8；西端连接营地，东侧形成宽敞的门前活动空间。西侧缓坡从营地地坪过渡至别墅地坪，周围 1.3 米肩部同时整平。铺装由真实地形三角形裁切，浮高仅 1.2 厘米；直接使用原地形碰撞与高度查询，避免叠加碰撞产生卡脚边缘。伸缩缝合并为一个网格；不在通行方向设置凸起路缘。

溪流在道路覆盖处隐藏水面，保留道路两侧和岛上其余河道，避免溪流水面穿过铺装。树干、树根与枝条继续使用分段碰撞，树冠保持柔性遮挡淡化，静态树林继续使用 MultiMesh。未新增实时阴影灯、动态树叶或高分辨率纹理。

素材来源、许可及文件大小记录在 assets/polyfork/manifest.json 与 CREDITS.md，新增模型为免费 GLB，CC BY 4.0。

验证：新增 test_villa_landscape.gd 检查路宽、路面射线高度、全路幅地面可行走性、树木退界、树间距与人物横向通行；test_tree_clearance.gd 扩展到两种新树的真实碰撞与伐木姿态。其余回归覆盖回家、采集建房、码头、宠物、钓鱼、镜头及移动端布局。离线 Blender 构图图只用于检查资产和场景布局，不等同于 Godot 真机画面或性能测量。保持不打开游戏预览、不自动启动手机 App。
