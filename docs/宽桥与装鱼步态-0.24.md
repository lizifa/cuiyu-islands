# 宽桥与装鱼步态（0.24）

## 桥面

主桥和末端桥面从 3.2 米扩大到 4.6 米，向西拓展，东侧船位和登船/靠岸锚点保持原位。桥面、支撑、碰撞、可走范围和左侧导向灯同步调整。钓台连接处仍使用不重叠的面，鱼护继续悬在水上，不被桥面盖住。

## 装鱼步态

原步行目标把 LeftFoot 放在负 X、RightFoot 放在正 X，与男女模型的实际脚位相反；而且仅在 2.2～3.1 秒临时使用这套脚位，其余时段恢复原站姿，导致交叉、并腿、张腿和滑步。

拿竿时记录角色真实左右脚的位置与方向，整个装鱼流程持续使用一致站位。后脚先迈、另一脚跟进，各自前移约 0.65 米；支撑脚保持在世界空间原地，摆动脚平滑抬起和落下，起步、停步与抄鱼到装鱼的衔接均连续。男女角色分别验证。

空抄网放到走道外侧，网袋折平贴近板面，不再跟着摘钩的手或穿进地板。鱼护、存档和收益规则沿用 0.23。

## 更活跃的伙伴

小狗随机选择等待的比例由 15% 降至 6%，等待约 0.35～0.8 秒，更多短跑、走动、找动物玩和摇尾巴，保留平滑加减速、安全跳跃及主人离开后的跟随。长目标受阻时尝试附近安全小步，减少反复站着。岛上按脚下真实地面检查支撑，不重复扣除边界安全距离；真实海面、悬空与过大高差仍拒绝通行。人在钓鱼时，伙伴也能从让位后的安全位置重新活动。

岸钓点击增加临时让位：先确认静态钓位没有被物体挡住，再让伙伴走到旁边等候，规划人物路线时把伙伴视为真实障碍。开始垂钓、取消或手动接管都会解除等待，保留双方碰撞。人物劳作等关键动作仍有更高优先级。
