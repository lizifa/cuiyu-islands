# 第一人称交互改版 0.30

历史记录：0.31 起默认已恢复稳定第三人称，本篇描述设置中可选的第一人称模式。详见《稳定第三人称与视角切换-0.31》。

## 默认操作

- 第一人称替代默认第三人称。左下摇杆 / WASD 按当前视线方向移动与侧移；右侧空白区域滑动 / 鼠标左键拖动转头。
- 指针按手指 ID 独立管理，抬起移动手指不会中断转头。转头松手即停，快速往返拖拽不积累多圈旋转。
- 水平视野 88°，保持横向视角；不将 88° 作为纵向视野，避免宽屏手机产生过大的横向畸变。手动转向总角速度最多 100°/秒，辅助转向最多 38°/秒。
- 固定站立眼位约 1.85 米，无走路晃动、呼吸摇摆、侧倾与奔跑变焦。坐下约 1.18 米、坐钓约 1.2 米、起身恢复站立高度；坐卧高度逐步变化。
- 自己的头、帽子、披风和身体只对游戏相机隐藏，角色选择预览仍展示完整角色。世界墙体、吊顶、楼板不隐藏。
- 手机设置增加转头灵敏度；默认第一人称不再提供原有平移 / 环绕模式切换。

## 靠近物体

- 准星结合物体外轮廓、距离和遮挡选择目标，按钮与准星下方显示对应动作；背对物体或隔着墙不出现它的操作提示。
- 沙发、冰箱、床、餐桌、浴缸、衣柜和电视使用实际对象边界；工作点保留内部就位锚点。
- 点击后沿用已有安全寻路与交易逻辑，不在靠近时自动变焦。电视可独立开关；坐下后保留开电视和起身按钮。
- 建筑和树木的对象包围盒缓存复用，避免每帧重复遍历大量模型。
- 小地图箭头改为当前视线方向，并使用简短的视野扇形。

## 双手与生活

新增程序化风格化双手、衣袖与手持工具，表现饮料瓶、水杯、烹饪勺、劳作工具和取放衣物。它们是独立的第一人称模型，不直接把第三人称手臂放到镜头前。

拿饮料、后退关门、喝水、走到垃圾桶和抛空瓶保留原有物品交易与动画状态，持有物品在等待和行走阶段保持显示。蹲下抚摸时视点下降，手掌追踪宠物实际头部。上床与起床使用床铺真实头部位置，独立控制视线，避免直接继承骨骼侧倾。躺下后可手动看周围，不强制持续回中。

## 钓鱼

1. 就位后进入准备状态；按住「甩竿」蓄力，松手才抛出。蓄力决定约 12～28 米抛投距离。
2. 双手持海竿，保留鱼轮、张力和按鱼重量变化的八段弯竿；鱼线连接实际第一人称竿尖与海面浮漂。
3. 等待时平缓坐下，浮漂有屏幕定位提示。咬钩提供文字、可关闭的双音提示与触感反馈；大鱼需要起身，再提竿收线。
4. 按住收线、松手卸力，保留断线与脱钩判定。
5. 抄网从左手伸出，鱼被托起后在眼前摘钩，再放入世界里的鱼护。实际种类、重量、数量和存储交易沿用原系统。
6. 钓鱼期间摇杆不触发离开，使用「收竿」明确结束；暂停时未完成的蓄力回到准备状态，不在恢复后自动抛投。

## 验证与限制

新增默认第一人称、输入、快速拖拽、遮挡提示、双手竿尖连接、完整钓鱼收鱼、30/60 帧上下楼、冰箱到垃圾桶、上床起床及手机比例检查。无窗口检查验证几何、状态和动作连贯性，不代替设备实际画面与舒适度验收；本轮不自动启动游戏或预览。

保留 `--third-person-camera` 命令行参数供开发对照与旧流程回归，不是默认玩法，也不从旧 camera.cfg 自动恢复。角色、宠物、物品和存档结构不变，不卸载应用。
