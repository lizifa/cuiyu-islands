# 宽室内镜头、手动楼梯与脱穿鞋 · 0.13.0

## 室内镜头

观察半径由 3.4 扩大到 5.2 米，垂直视野由 55 调至 74 度；镜头仍在当前楼层顶棚以下。构图略向下偏移，减少顶棚占比。无遮挡时的理论目标平面覆盖高度约为原先两倍，实际可见范围受家具、隔墙和观察位置影响。室内墙体与地面围合、近墙避让和拖动边界继续保留，室外镜头参数不变。

## 两种楼梯操作

靠近楼梯口仍显示“上二楼 / 下一楼”，点击后沿实体楼梯自动行走。也可以用摇杆走进右侧楼梯通道（入口转角约 x=7.3、z=3），沿楼梯方向控制移动；松手停下，可反向折返。自动通行过程中推动摇杆即可接管。手动输入与任务自动移动分开识别，避免自动任务误触发接管。

两种方式使用同一条连续路径和实体坡面碰撞。楼层在抵达目的层平台后切换，走到一半的存档使用出发平台安全位置。暂停时不移动，完成后恢复普通行走碰撞。

## 床边脱穿鞋与动作衔接

现有男女角色的鞋子均为独立附件。睡前先挂外衣，再走到床边坐下；逐只抬脚、俯身脱鞋，鞋子留在床旁，再抬腿上床躺下。起床依次睁眼、坐起、双脚移到床外、坐着逐只穿好鞋、站稳，最后取回外衣。利用实际鞋子网格分成左右两只；结束、取消及场景退出都会恢复原附件并移除临时网格，不修改背包资源。

站起时手部支撑平滑进入和退出，站姿到第一步行走增加 0.25 秒骨骼混合；床边行走使用连续动作时钟，避免阶段切换重置走路采样。上述处理针对动作衔接生硬；未进行本版手机帧耗时采样，不能据此断言所有性能掉帧均已解决。
