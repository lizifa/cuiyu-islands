# 别墅层高提升 0.29

- 每层净高从 3.8 米提升为 4.8 米，层间高差从 4.25 米调整为 5.25 米；二楼整体升高 1 米。
- 外墙、室内分隔墙、天花板、吊顶边框和楼板共同使用共享尺寸。吊顶边框下仍有约 4.59 米净高。
- 入户门和卫浴门调整为 3 米高，卫浴门上方补齐墙面。人物、床、沙发、冰箱、电视及其他家具保持原尺寸。
- 相机保留原有站立高度，普通行走观察点略微抬高至人物根节点上方 1.95 米，增加墙面上部的可见范围；楼梯仍使用原有入镜参考高度。
- 楼梯每跑 16 级，单跑水平长度 4 米，每级高约 16.4 厘米、深 25 厘米；扩大转角平台及对应楼板开口。踏面、碰撞、扶栏、路线和脚步采样共用尺寸。
- 上下楼增加水平观察距离保护，防止更高楼层的过渡让镜头落到人物头顶。可选镜头模式上下楼也使用封闭空间避障。
- 旧存档的楼层保持不变，进入别墅时按新楼面高度重新落地，不重置资源或进度。
