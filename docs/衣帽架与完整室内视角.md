# 衣帽架与完整室内视角 · 0.12.0

床与衣柜之间增加实体衣帽架。上床时先实际走到架子前，解下斗篷与帽子，伸手挂好，再走到床沿、上床躺下；起床依次睁眼、坐起、挪脚落地、站稳，再走到衣帽架取回并穿戴。女性角色只取放当前实际佩戴的附件。衣物挂在架上期间带有碰撞，结束或中断时清理。不是布料物理模拟。

原楼梯超出了主房间右墙范围，现在右侧加建完整室内楼梯间，保留连续两跑楼梯，补齐地面、围墙、顶棚与暖灯；二楼楼梯开口增加护栏，入口保持通行。楼梯仍通过实际路径行走，上下楼不传送。

镜头从室外俯瞰改为室内近距离跟随，固定在当前层顶棚以下。当前观察方向无遮挡时提前结束物理查询，避免每帧遍历全部观察方向。室内拖动范围收紧，靠墙时选择可容纳镜头的观察方向，避免镜头钻入家具和墙体；视角归位会清除室内镜头缓存。休息时跟随实际头部与躯干位置。封闭墙体、天花板及地面覆盖画面边缘，不再把海面或室外背景作为室内画面的一部分。小地图覆盖新增楼梯间。

新增 `interior_shell.gd`、`interior_camera.gd`；衣物动作在 `bed_motion.gd`，衣帽架布局在 `upstairs_rooms.gd`。`test_indoor_enclosure.gd` 检查两层 64 组位置与朝向的镜头空间、屏幕射线围合、家具避让，以及衣帽架碰撞、楼梯路径与开口限制。

使用实际骨骼和当前室内镜头导出后台离线图，核对床上姿态及围合效果。离线渲染不等于手机视觉验收；不打开编辑器、预览或自动启动游戏。存档保留。

2026-11-12 验证：37 组、2381 项计数检查通过，日志无脚本或运行错误；镜头查询提前结束优化后重新通过 204 项室内围合及 29 项镜头观察检查。iOS Release 0.12.0（30）已保留数据覆盖安装到「小书包」iPhone 12 mini，设备版本、严格签名及 perf_probe=false 均已确认。未自动启动，尚未做本版手机视觉验收；Android 未更新。
