# 场景运镜与固定摇杆（0.18）

## 行走与操作

普通行走先保留人物转身动作，持续移动约 0.25 秒后，相机以最多约 85°/秒缓慢回到行进方向后侧；不足 10° 的细小角度差不触发旋转。停止后不继续改变目标方位。墙体和家具仍由原有相机路径扫掠及边界约束处理，不用瞬移绕过障碍。手动观察后暂缓自动跟随，楼梯、船、钓鱼、床上动作及专用交互不使用普通行走跟随。

持续保持相同摇杆方向时锁定本次输入的世界行进方向，相机旋转不带着人物绕圈；明显改变输入方向或开始下一次推杆时，以当时镜头重新计算方向。自动寻路继续使用原有方向计算，右手操作镜头仍与左手摇杆分离。

左下摇杆内圆固定在大圆中心，拖动只改变三角箭头方向，移动强度仍由手指偏离中心的距离决定，松手停止。内圆与箭头继续使用同色合并绘制，外圈默认浅、按下加深。

## 按场景构图

- 走路：保持较远的空间视角，略向行进方向留白。
- 楼梯：沿用一键自动上下楼、脚步动作和后方中景。
- 开冰箱、取瓶、后退关门：沿用稳定斜侧中景，不套用喝水特写。
- 喝饮料/接水后喝水：以拿瓶那只手一侧的斜前方构图，目标约 2.35 米、58°视野角，高度依据角色头部计算。人物先自然转向空地，镜头预留稳定时间，再举瓶、喝下和放低。瓶口按瓶身倾斜后的几何位置对齐嘴部，轻微抬头；完整喝水动作约 3.2 秒。
- 沙发小憩：人物与电视共同构图，采用后侧 50°视野角，看清坐姿与屏幕；起身恢复原视角。电视视频仍由原有播放控制负责。
- 做饭：使用偏侧、抬高的 60°视角，同时展示手部、锅与食材；加入灶台锅和手持木勺，镜头先稳定，再开始搅动，完成后才扣原配方材料。
- 餐桌进食：斜前方较近构图，完成后退回远景。

交互镜头由 `home_camera.gd` 管理，普通行走由 `walk_camera.gd` 管理；同一时刻只有当前场景拥有镜头控制，结束/取消后释放。暂停不推进生活动作，切场景或更换人物会清理姿势和道具。

## 验证

新增 `test_cinematic_camera.gd` 检查固定内圆、箭头方向、行进方向稳定、后侧跟随、停步停止转向、电视构图比例、喝水瓶口与嘴部距离及烹饪构图。使用 headless 检查和后台离线几何画面，不打开编辑器、预览或手机游戏。离线画面不代表真机观感、触控与温度验收。

2026-11-12 交付验证：47 组测试累计 2590 项检查通过（包含受影响流程与最后镜头细调后的针对性重跑）。后台离线检查喝水、沙发和灶台构图，修正了沙发人物裁切和吊柜遮挡；灶台最终采用较高的斜侧特写，突出锅、食材与手部操作。Release 0.18.0（39）覆盖安装到「小书包」iPhone 12 mini，保留应用数据，没有启动游戏。签名检查通过；从隔离目录加载实际应用内 PCK，确认固定摇杆、稳定方向映射、沙发镜头、最终灶台镜头参数和完整电视视频均已交付，未启用性能采样模式。尚未完成本版真机触控、运镜观感和温度验收。
