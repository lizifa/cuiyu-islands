# 一楼地板闪烁修复 · 0.14.1

发现楼梯间地面和楼梯底部平台的顶面均在 y=0.675，重叠范围约 x=8.0–9.3、z=2.0–3.5。两块共面表面会争抢深度显示，也存在重复地面碰撞。删除多余的底部平台，使用已有楼梯间地面承担入口平台；其他平台、台阶和楼面高度保持不变。

原木地板缝使用15条独立、宽2.5厘米的细几何条，远处或斜视时容易出现细线采样闪烁。板缝现与主楼面共用一个表面，改用生成的小尺寸重复贴图，具有 mipmap 层级、线性与各向异性过滤；不再叠加细条几何。地板基础颜色和楼面碰撞保持原配置。

室内相机裁剪范围改为0.12–45米，离开室内恢复0.05–2400米，避免室内继续使用面向远海的深度范围。没有调整镜头跟随方向、层高、人物动作或存档。

`test_floor_surfaces.gd` 检查重复平台移除、入口多点恰有一个同高度地面、纹理 mipmap 与过滤、细几何条移除，以及进出室内裁剪范围恢复。

最终7组相关检查、326项计数检查通过，包括上下楼、镜头连续性、人物可见性和室内布局。无窗口检查无法验证手机GPU上的闪烁表现，仍需本版真机体验确认；不打开预览或自动启动游戏。

0.14.1（35）已保留存档安装到「小书包」iPhone 12 mini，设备版本、严格签名及 perf_probe=false 已核对；未自动启动。本条为上一版交付记录。
