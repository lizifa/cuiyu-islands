# 钓鱼台与岸钓玩法

当前为iOS 0.7.2：坐钓、撒饵、大鱼起身与抄网已接入，钓鱼不消耗精力。当前规则见[钓台装备与动物碰撞](钓台装备与动物碰撞.md)。以下0.5.0—0.6.0记录属于历史实现，旧成本和“无鱼饵”限制已被替代。

## 0.5.0 初始实现

## 位置与操作

营地南侧船边，现有码头左侧新增5×4米木制钓台。沿码头向海走，再从左侧开口进入；站近钓位，右下交互出现「钓台垂钓」。钓台与码头高度均为0.65米，有实体甲板、边缘栏杆、长凳和鱼桶；标牌仅靠近时显示，保留原登船通路和上船操作。

1. 点击垂钓，人物持竿甩向海面，鱼线和浮漂随抛物线落水。
2. 等待约2.5—5秒，浮漂下沉并显示咬钩提示；2秒内点击「提竿！」。
3. 中鱼后长按「收线」，松开卸力；把张力保持在绿色范围，收线进度向右填充。右下原交互按钮也可提竿/长按收线，电脑收线阶段可按空格。
4. 收线完成后播放鱼出水、甩尾及收竿过程，落鱼完成才增加鲜鱼×1。结果页可再甩一竿或离开。

过早提竿、错过咬钩、张力极端持续超过0.5秒均跑鱼，不发鱼。摇杆移动或「收竿离开」中止；暂停、菜单、失焦冻结阶段计时并释放面板长按状态。换人物、地点或登船清理旧骨骼和钓具。

## 动作与表现

使用现有人物骨骼的双臂程序化IK，鱼竿跟随右手，左手扶竿；甩竿、提竿、收线、摇轮、浮漂下沉、水面涟漪、鱼线张力及鱼出水由阶段驱动。是首版程序化动作，并非新增专业动作捕捉片段。鱼模型复用已署名的Polyfork reef-fish-base，不新增外部资产。当前无钓鱼音效、鱼种稀有度、拟真鱼线物理或鱼饵系统。

鱼竿、浮漂、摇轮与涟漪采用低分段几何，鱼线单个ImmediateMesh复用更新，甲板缝隙用MultiMesh合并提交。仅垂钓期间创建钓具；结束后释放，不改默认30帧省电策略。

## 成本与存档

抛竿前检查精力至少10、背包能容纳1鱼、岛上且天气非雷雨/大风。开始时推进20个游戏分钟，并额外扣2精力；时间推进仍有原本食水和精力消耗。成本立即存档，中断或失败不退成本；落鱼只结算一次。背包在过程中变满则放生，不超容量、不重复发鱼。「好鱼竿」让收线速度提高25%。

钓鱼阶段不跨重启恢复；重进为正常站立，已结算鱼和正常生存进度保留。原出海捕鱼和旧采集菜单沿用原规则，本次新增的是独立岸钓入口，不强制替换所有捕鱼方式。

## 验证

27项岸钓检查覆盖真实走上码头和钓台、实体地面、持竿与鱼线、成功落鱼及单次奖励、暂停、过早/过晚提竿、断线/松线、背包预查及过程中满包、低精力、摇杆接管、换人物与地点后的清理。原694项检查通过，合计721项，UI smoke另行零失败。钓台标牌修改后HUD93项通过，最终UI文字及低分段几何调整后岸钓和smoke再次通过。

均为headless逻辑和物理检查，未自动启动手机或桌面预览，未完成本版动作观感、手机触摸手感或新场景长期热性能验收。iOS Release 0.5.0/build13覆盖安装到小书包，保留数据；Android最近安装版仍为0.4.1。

## 0.5.1 手机触感反馈

使用Godot Input.vibrate_handheld接到已有动作事件，不改变判定、进度和奖励。默认开启，可在设置的「钓鱼触感反馈」关闭，独立保存到haptics.cfg；不修改生存存档或省电偏好。设置开关触摸高度48，设置面板调整为440高。

| 时机 | 震动时长 | 强度 | 同类最短间隔 |
| --- | --- | --- | --- |
| 甩竿 | 24毫秒 | 0.25 | 250毫秒 |
| 咬钩 | 65毫秒 | 0.80 | 500毫秒 |
| 提竿 | 45毫秒 | 0.65 | 250毫秒 |
| 正常长按收线 | 12毫秒 | 0.22 | 650毫秒 |
| 张力过高 | 35毫秒 | 0.70 | 700毫秒 |
| 线太松 | 18毫秒 | 0.30 | 700毫秒 |
| 成功落鱼 | 75毫秒 | 0.85 | 500毫秒 |
| 跑鱼或未能入包 | 45毫秒 | 0.35 | 500毫秒 |

任意两次脉冲至少间隔80毫秒，避免重叠；危险张力时只请求警示，不叠加普通收线轻震。没有延时震动队列或持续马达循环。暂停、菜单、失焦、性能测量模式、关闭设置均禁止新的脉冲；已有单个短脉冲交由系统完成。当前没有通过震动改变张力值或成功率。

iOS走系统原生接口，不增加插件。Android预设启用VIBRATE权限，但本轮仅更新iPhone，旧Android安装包不会自动获得触感。桌面与headless测试只验证事件，不驱动设备震动。

新增HAPTICS 23项：限频、全局间隔、事件强弱层级、暂停/后台/测量禁用、开关独立性、实际钓鱼中的甩竿/咬钩/提竿/张力/收线/成功，以及成功不重复触发。全量744项计数检查通过，UI smoke零失败。正常Release 0.5.1/build14覆盖安装小书包，保留存档，未自动启动；未亲手感受震动强弱，未测量马达能耗或重新进行热性能采样。

参考：[Godot Input.vibrate_handheld](https://docs.godotengine.org/en/stable/classes/class_input.html#class-input-method-vibrate-handheld)。系统触感设置及硬件支持可能影响实际效果，事件层检查通过不等于真机震感验收。

## 0.6.0 海竿远投

海竿更新为3.6米，浮漂距钓位约20米；竿身随张力弯曲，收线交替提竿和摇轮，左手跟随摇柄，脚步保持站稳。镜头跟随甩竿、收线与落鱼阶段平滑调整，结束恢复。岸钓检查由27项扩展为34项，具体交付范围见《海上交互与镜头》。
