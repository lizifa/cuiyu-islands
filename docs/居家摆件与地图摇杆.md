# 居家摆件、地图与摇杆 · 0.9.4

茶几增加托盘、两只茶杯和杯碟，餐桌增加水果盘与五个低多边形水果；均为原创建模的程序化装饰，不改变库存、食物数量或资源消耗。修正四把餐椅朝向：左排面向右、右排面向左，椅背在外侧、座位面向餐桌。

一楼原先的悬空书板改成完整书柜，含背板、侧板、底柜、顶板、四层书架和彩色书本。书柜放在右后墙、正面朝客厅，以便从常用镜头看到书本，同时避开书桌和楼梯通道。柜体有实体碰撞；旧存档若落在新增书柜占地内，恢复到柜前安全位置，保留进度。

左下摇杆仍保留原尺寸、死区、多指归属和操作布局：默认仅显示中间小圆及方向三角，不绘制外圈或大底盘；按住时才淡显外圈和底盘。三角形位于小圆内，随摇杆方向旋转，松手后保留最后方向。床上仍忽略移动输入，不会因转动摇杆起床。

地图仍在左上角，按「现有位置再靠左一点」处理，向左移动 8 个逻辑像素，保留屏幕刘海安全区。点击小地图展开，点击大地图图面还原，不设置独立关闭按钮；还原后小地图位置与大小不变。支持原生触屏与鼠标，忽略触屏模拟出的重复鼠标事件，避免展开后又立刻收起/重新打开。大地图按可用高度调整，兼容宽屏与平板。

新增 test_home_details.gd 覆盖摇杆四方向角标、按压/释放状态、地图触屏展开还原、无关闭按钮、还原位置、模拟鼠标去重、宽屏和平板安全区、摆件存在性、书柜碰撞和旧档恢复、四把椅子朝向。原有家具间距、沙发就位、楼梯和床铺动作继续验证。摆件与书柜做后台离线构图检查，未打开游戏预览；真机视觉与触感需实际运行查看。
