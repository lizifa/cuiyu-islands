# 统一舒适镜头修复

默认开启「设置 → 舒适镜头」。配置单独保存在 `user://camera.cfg`，不修改生存存档。关闭后可选择原有跟背与交互特写；这套旧模式仍可能引起不适，建议保持开启。

## 默认体验

- 普通行走只跟随位置，人物转身不会强制相机绕到背后。跟随有 0.25 米位置死区，取消速度方向带来的镜头偏移。
- 平移观察松手后保留位置，主动点击回中；手动旋转、看太阳和归位继续可用。
- 冰箱、喝水、做饭、吃饭、沙发及床上动作保留宽景与既定观察方向，不在每个动作中切换近景、方向和视野角。交互结束也不覆盖玩家期间手动选择的朝向。
- 点击垂钓时以一次短暂暗场淡入建立包含人物和远处浮漂的宽景，保持玩家朝向；紧凑状态提示在顶部空位中避让人物和小地图；等待、收线、抄网、装鱼连续使用该视图，退出不绕拍恢复旧镜头。保留最后的观察尺度，避免每条鱼都重复拉远拉近。
- 上下楼按两段台阶使用校准后的固定室内宽景，人物真实走台阶，每段镜头保持不动。开始、楼梯中段及到达时用短暂暗场淡入交接镜头，避免经过楼板时推拉、绕转；视野角保持 80°。
- 离开别墅恢复室外 44° 视野角及对应场景初始化朝向，清除旧镜头运动状态；地点切换以短暂暗场淡入直接建立新场景镜头，不跨地图飞行。
- 暂停、后台及打开抽屉时冻结镜头；恢复后每次更新最多使用 0.05 秒，避免累计时间追赶。

## 统一运动约束

`orbit_camera.gd` 在世界更新之后执行，统一应用朝向、距离及最终视线。舒适模式的轨道转速暂定上限 30°/秒、轨道角加速度 75°/秒²，距离变化最多 2 米/秒。碰撞调整和观察点变化产生的最终视线转速同样经过约束，保持水平线。它们是本项目首版调参值，不是通用舒适性标准。

室外相机从上一帧真实位置做球体扫掠，移动预算为 8 米/秒；室内继续使用连续扫掠和滑动，避免遮挡解除直接跳远。安全碰撞优先，已陷入障碍或地点初始化等恢复情形允许重新建立安全位置。此版没有重新设计建筑遮挡淡出系统。

摇杆每次按下锁定相机的水平移动基向量，持续使用当前摇杆角度计算移动方向。缓慢转动也能累计响应，相机自动变化不会改变一次持续拖动的世界方向。

## 验证与边界

新增 `tests/test_camera_comfort.gd`，覆盖默认模式、渐进摇杆转向、固定输入基向量、取消强制跟背、主动归位、30/60 帧最终角速度和水平线、室外位移预算、暂停、钓鱼阶段视角一致性、人物/浮漂投影、交互宽景、楼梯机位、动作结束保留手动视角及室外视野恢复。

原有 `test_home_camera.gd`、`test_cinematic_camera.gd` 明确切换到可选旧模式，继续验证原有近景流程；默认模式由新套件与生活交互套件验证。观察测试更新为松手保留视角的行为。

只执行 headless 测试，不自动打开编辑器、预览或手机游戏。自动测试可以验证数值、投影、碰撞和流程，不能证明真实手机上的画面舒适度；仍需在目标手机上检查帧时间、镜头构图与实际不适感。此轮未打包、未安装，也未进行手机性能采样。

本轮验证结果：21 组相关套件、720 项检查通过，包含 26 项新增舒适镜头检查、32 项室内连续性检查及 168 项钓鱼 HUD 检查。均为无画面验证。
