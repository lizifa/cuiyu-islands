# 海景别墅与居家生活

岛上新增可直接入住的双层海景别墅，不消耗资源，也不改变原有木屋任务进度。打开任务面板选择「回家 · 海景别墅」，人物会实际寻路到门前并进入；也可自行走近门廊交互进入。船上需要先靠岸。室内右上角提供「走出别墅」快捷入口，大门也可正常交互离开。

## 房间和操作

- 一楼：客厅沙发可坐下持续恢复并开关电视，厨房可取水和制作风干鱼，餐厅可吃已有食物，书房和宠物休息角营造家的生活空间。
- 二楼：主卧和次卧、衣柜、浴室、阅读角与阳台。床可睡到次日清晨；洗澡每天一次，恢复少量健康和精力；收纳入口打开现有背包，不提供独立仓库。
- 走近楼梯使用交互切换楼层，目前为楼层传送，不是连续攀爬楼梯。室内采用剖面视角，没有天花板，遮挡人物的后墙会淡出，室外海面、森林碰撞与降雨在室内停用。

家具使用 Polyfork CC BY 4.0 的沙发、床、餐桌、浴缸和冰箱，来源见 assets/polyfork/CREDITS.md；别墅建筑与其余模块由代码搭建。室内休息、食水和制作沿用现有时间、背包与恢复规则，不增加免费交易或食物。

## 存档与验证

保留原存档格式，新增 home_floor 字段；旧档缺字段默认一楼，兼容 JSON 数字类型。若旧存档人物位于新建筑占地中，自动移到门外安全位置。室内存档可恢复地点和楼层。

33项别墅检查覆盖真实角色寻路、进出、家具通行、上下楼、厨房、洗澡、睡眠、磁盘存档恢复与旧档迁移。离线场景渲染用于检查布局，不代表 Godot 真机画面或性能验收。未自动打开预览或手机应用。
