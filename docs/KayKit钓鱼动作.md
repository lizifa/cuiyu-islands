# KayKit 钓鱼动作

接入作者免费CC0包中的7段真实动画，详情及原始许可见 `assets/kaykit-fishing/README.md`。

## 技能与阶段

五槽和既有条件、资源结算不变：

1. 主按钮：蓄力抛竿 / 咬钩提竿 / 长按收线 / 抄网，跟随原有阶段。
2. 常用辅助：原有撒饵 / 收线卸力等情境操作。
3. 退出：原有收竿离开。
4. 鱼护：原有查看鱼护。
5. 空槽：维持置灰；钓具入口仍在结果阶段的槽2。

实际技能名称和可用条件继续由 fishing_session.sync_controls 控制，动作锁定及空槽规则沿用原实现。

动画映射：抛竿Cast、等待Idle、咬钩Bite、提竿Tug、收线Reeling、高张力或卸力Struggling、收近鱼Catch。没有新增资源扣除或奖励；起鱼结算、抄网和装鱼阶段保留原流程。

重定向上半身并平滑衔接，腿部保持原坐姿和站姿。鱼竿握点跟随右手，左手保持握竿/摇轮IK；抄网和装鱼仍用原接触动作。暂停停止计时；退出清空动画缓存并恢复人物。

验证：素材导入、七段动画状态映射、实际骨骼运动、有限姿态、脚部保持、抄网接管、退出清理与重新进入的headless测试。没有打开游戏、打包安装或做真机视觉验收。

验证结果：新增动画定向测试通过；浮漂落水20项通过。装鱼步伐测试13项通过、3项失败；在隔离副本中关闭新增动画后，仍出现相同3项失败（码头实体地面检测、两个人物分支的脚间距断言）。未修改这些历史测试或扩大修复范围。
