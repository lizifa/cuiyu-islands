# 居家动作、层高与楼梯跟拍 · 0.14.0

## 六项修复

1. 沙发坐姿：对实际沙发网格做竖向三角形求交，获取坐垫表面高度，再根据角色缩放和骨盆余量定位；坐位向坐垫前部调整。腿部使用两段骨骼 IK，让双脚落在地面，避免骨盆压入坐垫、脚伸进沙发。男女角色分别验证。
2. 抚摸宠物：双脚锁定在开始蹲下时的地面位置，骨盆降低到适应宠物头部的高度，屈膝并前倾，再用手臂 IK 触摸头部，最后站起。狗、猫、兔及男女角色均验证手部接触与脚部落地。
3. 摇杆方向标：改为宽而扁的三角形，底边贴内圆外缘，随当前移动方向旋转。保留默认隐藏外圈、按下微弱显示的交互。
4. 室内层高：`villa_dimensions.gd` 统一底层地面0.675、层间升高4.25、净高3.8米。两层围墙和顶棚、二楼地面与家具、楼梯坡度与平台护栏、床铺和镜头一并调整。旧存档进入室内时按新楼面高度恢复安全站位，不清档。外部别墅为独立展示模型，本轮未重做外立面。
5. 上下楼接入：楼梯按钮绕过通用的操作圈就位逻辑；从当前位置检查直达楼梯入口的通道，需要时补一段转角对齐，不再先回到圈圈。路径去除重复站位，保留自动行走、摇杆接管和转角折返。受阻时恢复出发位置、脚部碰撞及宠物。
6. 楼梯镜头：采用人物后上方的跟拍位置，转弯时平滑转向，并在楼板开口范围内保持安全距离。看向人物上身，预留顶部界面空间；被遮挡时收近，抵达楼层后平滑恢复室内宽视角。保留上一版路径扫掠和限速，避免重新引入镜头跳位。

## 验证范围

新增 `test_home_motion.gd`，检查3.8米净高、箭头比例与外缘位置、直接接入楼梯，以及上下楼全程1030个采样点的镜头可见性。两段直线楼梯的稳定跟随段确认镜头位于人物后方。补充宠物脚部 IK 检查，更新层高相关测试坐标；阻挡恢复测试改为阻断实际楼梯通道。

后台离线渲染检查沙发坐姿、蹲下摸狗和两跑楼梯背后跟拍，未打开编辑器或游戏预览。离线图与无窗口检查不代表手机真实帧率和最终视觉验收。

最终 41 组、2477 项计数检查通过，包含完整游戏流程、镜头连续性、上下楼、宠物、床铺、沙发和移动端布局。最终构图调整后额外重跑可见性检查。
