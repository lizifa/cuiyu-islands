# 二楼主卧、电脑与卫浴布局 · 0.10.0

按照用户参考图的北侧三分区与南侧空过道布局重排二楼；一楼客厅、地图与摇杆行为沿用。

## 左上主卧

只保留一张主床，床中心移至 `(-4.8,0.7,-4.05)`，实际床头与北墙内侧相隔约 1 厘米。保留两个棕色床头柜，在左侧柜上放小台灯。绿色地毯覆盖卧室地面；棕色高衣柜位于床右侧并紧贴隔墙，远离卧室入口。床侧与床尾使用人物大小的碰撞查询验证可通行。

床边交互点、上床姿态和起床位置随床同步移动；原有披风/帽子收起、起床恢复、渐进休息和睡到清晨继续使用。上床后仍忽略摇杆，只能点击起床主动离开。旧存档若落在新床或衣柜占地内，恢复到空过道，不清除库存、任务或人物数据。

## 中间电脑区

移除第二张床，使用棕色书桌、黑色高背电竞椅。薄边显示器约 0.8×0.45 米，占 3.2 米桌宽的四分之一；放在桌后居中位置。桌上有键盘和左后角小音箱，书桌右侧带三层开放书格和彩色书本。

椅子后方留有退让空间，验证向后平移 1 米的占地不碰隔墙或家具；本次是摆放与空间检查，没有新增拖动家具或电脑玩法。

## 右侧独立卫浴

浴缸中心 `(5.7,0.7,-4.7)` 与洗手柜中心 `(7,1.2,-2.5)` 保持原位，补齐靠内侧的马桶、洗手盆、水龙头与镜子。蓝色地垫覆盖卫浴内部。新增透明滑动门，靠近自动打开、离开后关闭；门向侧边滑行，避开浴缸、马桶、洗手台和门框。人物或宠物接近时保持打开，暂停时停止动作。

## 下方过道与楼梯

移除二楼下方的沙发、休闲桌椅、地毯和盆栽，仅保留木地板与建筑围栏。过道连通卧室、电脑区与卫浴。

双跑楼梯整体向南平移 3.5 米，室内上下楼入口改为 `(6,0.705,2)`，落在右下侧过道；一楼的对应开口和入口同步移动。仍然是真实连续楼梯移动，两层保留在场景中，在平台抵达时切换剖面显示，不点击传送。

## 验证范围

新增 test_upstairs_layout.gd 覆盖一张床、无沙发、床头贴墙、衣柜与地毯、电脑配置、屏幕比例、卫浴三件套原位、地垫范围、25 处过道碰撞查询、床侧与退椅净空、右下楼梯和滑门开合，并检查滑门行程多个位置不与门框/家具碰撞。test_villa.gd 与 test_home_actions.gd 更新为新楼梯/床位置，验证实际行走、进卫浴、上下楼、男女躺床和起床。
