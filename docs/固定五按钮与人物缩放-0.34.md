# 固定五按钮与人物缩放（0.34 / build91）

## 五个按钮实际固定

右下五个按钮在游戏操作状态始终可见，保持上一版确认的弧形位置和大小。普通步行、室内、坐卧、锻炼、上下楼、钓鱼各阶段、船上均不再单独隐藏按钮。没有对应技能时显示灰色圆底和短横占位，不使用虚假的动作名称；点击不会执行任何操作。已有技能暂不可用时同样置灰，并正确释放正在按住的输入。

当前已有操作继续使用原槽位：船上五项全部保留；陆地启用既有交互、奔跑和建造/回船；休息、锻炼等只启用当前真实操作；钓鱼的暂不可用辅助操作保留为灰色。此次没有凭空新增其他预制体的新玩法，也不声称每个物体均已有五个真实技能。

菜单、设置、地图、帮助、确认等弹窗及暂停时，整个按钮组隐藏，关闭后恢复。已更新项目规范：允许空槽，不再强制为填满五个槽位编造操作。

## 人物再缩小三分之一

场景内男女角色模型统一乘以2/3，身体、衣服、帽子及骨骼随模型等比缩小。保持既有镜头距离、FOV、移动速度、碰撞和家具尺度。开局选人预览维持可辨认的原有展示大小。

哑铃和瑜伽抬手目标高度同步按比例适配，避免缩小后仍伸向原高度造成动作僵直。坐姿、划船和居家交互沿用已有骨骼定位流程。
