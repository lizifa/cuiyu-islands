# 固定五技能规范

用户最新确认：右下固定五个技能按钮；没有技能的槽位可以置灰。每个可交互预制体都使用同一套五槽，不强制填满五项。本规范适用于《晴耕雨航》全项目，包括既有预制体的后续改动及新预制体。

## 固定布局

五个槽位始终保留位置与大小，不因当前对象增减按钮或重新排序：

| 槽位 | 位置 | 责任 |
|---|---|---|
| 1 | 右下大按钮 | 当前对象的主要动作及其下一步 |
| 2 | 右上辅助按钮 | 常用辅助动作 |
| 3 | 左上辅助按钮 | 对象的另一主要能力或场景切换 |
| 4 | 左侧小按钮 | 情境辅助动作 |
| 5 | 外侧小按钮 | 情境辅助或退出、返回动作 |

沿用已确认的弧形安全布局。图标、短名称、启用状态随对象和动作阶段变化，槽位位置不变。五个触摸热区互不重叠，最小48逻辑像素，保留安全边距，不加包围整个按钮组的大框。

## 每个预制体的要求

1. 为已实现的相关操作分配槽位，剩余空槽显示灰色占位，不可点击；可包含一个动作链中不同阶段的同槽替换，例如撒网→收网、抛竿→提竿→收线、坐下→起身。
2. 每项明确触发距离/朝向、条件、人物与道具动作、物体反馈、消耗与收益、完成状态及取消/中断行为。
3. 没有动作、反馈或用途的假按钮不计为技能。五个槽不能只是同一操作改五种名字，也不能用无关的地图/背包/设置来凑数。
4. 条件不满足时保留该技能，置灰并说明原因，例如距离不够、需要先收网、背包已满。未实现功能不能伪装为已有技能；没有技能时使用不带动作名称的灰色占位。
5. 新旧对象均固定五个按钮；只有一至三项操作也可以接入，其余置灰。五槽显示已完成与五个真实技能均已实现是两件事，报告时要区分。
6. 进入/离开交互、切换对象或动作阶段，不移动按钮。动作进行中锁定冲突操作；暂停、重置、切场景和取消时正确释放输入、动画及临时道具。
7. 普通移动状态也保留五槽；需要明确对象的技能在没有目标时置灰，不应把不相干的远处物体技能混在一起。全局任务、背包、设置仍由原入口提供。

## 船上五技能（已有实现基线）

| 槽位 | 技能 | 状态规则 |
|---|---|---|
| 1 | 撒网 / 收网 | 投网、等待、拉网、重新取桨依次变化 |
| 2 | 加速 | 按住生效，放网、靠岸准备等阶段禁用 |
| 3 | 靠岸 / 登岛 | 接近有效码头才启用，先停稳摆正再下船 |
| 4 | 停船 / 继续航行 | 渔网及靠岸动作中锁定 |
| 5 | 返航主岛 / 取消返航 | 存在冲突动作时禁用 |

## 验收

- 不同交互对象及其各阶段始终使用相同五槽，图标和短名称与实际动作一致。
- 已有技能均有实际反馈；空槽明确置灰，未实现项不冒充可用项。
- 不满足条件时置灰且能理解原因；不会因无法点击而永久卡住退出/返回操作。
- 手机比例与安全区内热区不重叠、不遮挡主要人物和关键动作。
- 暂停、切换、重置与打断后，没有重复结算、残留动作、错误输入或多出来的按钮。
