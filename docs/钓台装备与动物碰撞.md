# 钓台装备与动物碰撞 · 0.7.0

## 一次完整岸钓

从码头左侧开口进入钓台，靠近后点击“钓台垂钓”。人物甩竿后坐到凳子上等待，钓到普通鱼可坐着收线；大鱼咬钩后起身站稳，提竿与摇轮交替收线。大鱼拉力更大、收线较慢，需长按和松开控制张力。收至岸边出现“使用抄网”，点击后左手持网入水、托鱼提起，完成才结算鲜鱼×2；普通鱼自动使用抄网，鲜鱼×1。错失咬钩、张力失控、取消及满包均不发奖励，失败不退既有时间与饵料。

面板“制饵”用浆果×1制作饵料×3，无精力门槛。等待时点击“撒饵”消耗1份，每竿最多一次，有投饵轨迹；剩余等待时间缩为60%，最低1.5秒。普通大鱼概率20%，撒饵后55%，已有好鱼竿再加10个百分点。提高概率不保证大鱼，也不会直接发鱼。

岸钓每竿仍推进20游戏分钟，制饵推进5分钟；岸钓、持续垂钓及旧“捕鱼”入口均不消耗精力，零精力可以开始。食水及时间照常变化，恶劣天气仍禁止岸钓。暂停和后台冻结阶段并释放长按，移动、切换人物、地点及登船取消钓鱼。坐姿位置不写入站立存档，离开恢复原来的安全位置。男女角色按实际骨骼高度对齐凳面。

## 装备与场景

参与交互：凳子、3.6米海竿、纺车轮、鱼线与浮漂、饵料、抄网。补充陈设：竿架、备用海竿、饵料桶、鱼护、钓箱、量鱼垫、备用线轮、备用浮漂、钳子与摘钩工具。后者目前不设独立耐久、收纳或量鱼玩法；“钓具”按钮可查看清单。没有宣称已经实现所有拟真钓具。

装备为与现有木制钓台一致的低分段程序化模型，鱼仍复用Polyfork素材；动作沿用骨骼IK。钓台凳子、桶等大件有实体碰撞，细小的手持工具不作为堵路墙体。陈设放在侧边，保留码头到钓位的横向通路。当前没有新增专业动作捕捉、钓鱼音效或真实水动力。

饵料作为背包物品保存，旧档缺少该字段时补0，不重置已有物资，不赠送无限饵料。大鱼按2份鲜鱼进入原贸易、烹饪规则，不另建鱼种经济。

## 人物与动物的阻挡

原宠物与陆地动物是Node3D，直接更新位置，只检查地面，人物可以穿过它们。现在狗、猫、兔及森林陆地动物使用CharacterBody3D与模型尺寸碰撞体，通过move_and_slide移动；朝向变化先检查空间。人物与动物双方都受实体阻挡，跟随会被树木、石头、家具、建筑和其他动物挡住。

宠物发现玩家正在走向自己时，先尝试向两侧让路；窄栈道无法侧让时尝试向前让路，所有动作仍经过碰撞。自动寻路不把宠物当前位置永久烘焙为静态墙，实际移动仍会碰撞。换场景时宠物只在附近可站立且无重叠的位置出现；无位置则暂时隐藏并重试，避免生成在玩家身体内。登船后宠物作为乘员关闭实体碰撞，下船恢复。抚摸调整了接近距离与上身前倾，使手能触及头部且身体保持在外。

既有树根、树干、岩石、家具、船体与码头阻挡保留；海鸟、水下鱼和视觉粒子不作为陆地障碍。并非把所有可见像素都变成碰撞墙，也没有实现动物完整导航系统。

新增FISHING KIT 34项、ANIMAL OBSTACLES 14项，覆盖零精力钓鱼、旧入口、旧档饵料迁移、真实凳面坐姿、男女骨骼对齐、投饵扣费、大鱼起身、显式抄网、单次结算、安全退出，以及三种宠物双方移动的逐帧碰撞与8只陆地动物的实体配置。既有回归随UI内容增加6项，加新增48项，共1019项计数检查通过，UI smoke零失败。原套件中受物理移动接口变化影响的测试已更新并复跑，修船后自动登船、别墅通行和抚摸检查通过；最终有效日志无SCRIPT ERROR或ERROR。
