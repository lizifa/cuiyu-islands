# 钓鱼坐姿与分阶段机位（0.35）

## 改动目的

此前岸钓的体验问题有三处：按「开始垂钓」后人物在 19~20 米外、约 25° 俯角处只有 60 px 高；抛竿时是站姿，抛完才坐下；最后 0.9 米是冻结姿势滑行，且「就位中」把主按钮禁用 3~4 秒。

本次统一为「坐下 → 抛竿 → 等口 → 起竿 → 收线 → 抄网 → 装鱼护」，并按阶段切换机位，把人物放到画面主体位置。

## 操作流程

| 步骤 | 人物 | 机位 | 可用槽位 |
| --- | --- | --- | --- |
| 点「钓台垂钓」 | 寻路到钓台，再走完最后 0.9 米（两步交替抬脚），坐上钓凳 | 先保留钓台全景，到达后 0.25 秒淡切到坐姿近景（约 6.5 米、12° 俯角） | 主按钮「就位中」约 0.5 秒，随后「甩竿」 |
| 抛竿 | 坐姿，竿角抬起 2.15 rad 后压到 0.35 | 坐姿近景，浮漂 20 米处仍在画面内 | 主按钮蓄力，「撒饵 / 制饵」 |
| 等口 | 坐姿，竿角以 ±0.03 rad 呼吸式微动 | 双人位远景（11 米、15°），人物约 160 px，浮漂在画面上方 | 「撒饵」，主按钮待咬钩 |
| 咬钩 / 起竿 | 小鱼保持坐姿，大鱼起身 | 低角度近景（5.2 米、9°），看竿身弯曲 | 主按钮提竿 / 收线，辅助按钮转「卸力」 |
| 收线 | 小鱼坐姿，大鱼站立 | 同上，不切镜 | 长按收线、松开卸力 |
| 抄网 | 起身半蹲 | 近水低机位（4.8 米、24°），抄网入水可见 | 主按钮抄网 |
| 装鱼护 | 起身两步走到鱼护 | 紧凑机位（4.2 米、26°） | 主按钮装鱼 |

同一机位分组内只更新参数，不重复切镜；跨组时用 0.25 秒黑场淡切，避免突兀跳变。

## 相机实现

`stable_third_person_camera.gd`

- 新增 `focus_activity(key, at, angle, radius, elevation, snap)`：`snap` 为真时当帧写入 `pivot / current_arm / stable_yaw / stable_pitch / render_yaw / render_pitch`，并同步 `camera.global_position`、`camera.rotation` 与碰撞探针，因此机位是一次成型的切镜，而不是从 38 米外慢慢吊臂。
- `render_pitch` 必须取负（相机 X 轴向上为正），否则会抬头把水面和浮漂甩出画面——本次修复的首要问题。
- 新增 `activity_settled`：钓台接近阶段为 `false`，切到坐姿机位后为 `true`；`activity_view_ready()` 在未 settled 时返回 `false`。就位门控因此从 3~4 秒缩短到约 0.5 秒（只覆盖最后 0.9 米走路）。
- `activity_view_ready()` 改为校验人物头（+1.35 m）与脚两点、屏幕 6%~88%；仅在 `activity_radius >= 10` 的等口机位才附加校验浮漂，近景与远景构图解耦。

`fishing_session.gd` 机位配方（相对钓凳 `SEAT` 的偏移 / 偏航 / 臂长 / 俯角）：

| 分组 | 偏移 | 偏航 | 臂长 | 俯角 |
| --- | --- | --- | --- | --- |
| 坐姿 / 抛竿 | (0, 1.05, 0.1) | π-0.55 | 6.5 | 12° |
| 等口 / 撒饵 | (0, 0.95, 5.0) | π-0.42 | 11.0 | 15° |
| 起竿 / 收线 | (0, 1.15, 1.0) | π-0.34 | 5.2 | 9° |
| 抄网 | (-0.6, 1.0, 2.2) | π-0.5 | 4.8 | 24° |
| 装鱼护 | (0, 1.02, 0.7) | π-0.35 | 4.2 | 26° |

## 人物与操作

- 坐姿贯穿全程：`ready / charging / casting / waiting / chumming / bite / 小鱼 hooking / reeling / result` 均 `seated_target = 1`，坐下收敛速率 3.2~4.2 / 秒；仅在 `standing`、大鱼 `hooking / reeling`、`landing`、`storing` 起身，保证抄网与装鱼时双脚踩实。
- 最后 0.9 米改为 `1.35 m/s` 的靠近速度，并用新增的 `player.fishing_join_walk(progress, direction)` 通过 `grounded_pose.leg()` 交替抬脚（两步、抬升 0.14、步幅 ±0.36），不再冻结滑行。靠近期间 `fishing_anchor` 跟随身体，姿态与鱼竿握点保持一致。
- 握点按肩部锚定：坐下后改用肩部相对偏移，避免骨盆下降后手臂够不到握点（测试 `rod follows actual wrist during cast` 由 0.39 m 误差回到 0）。
- 门控：主按钮不再因构图校验禁用；仅剩「就位中」约 0.5 秒，标题随之切换。`interact()` 在未 settled 时忽略一次点击，防止站着抛竿。
- 等口阶段竿角叠加 `sin(elapsed × 1.1) × 0.03` 的呼吸式微动，配合浮漂轻微起伏。

## 五技能槽

- 槽 1 主按钮：甩竿 / 提竿 / 收线 / 抄网 / 装鱼（随阶段换名，不再有「就位中」长时间置灰）。
- 槽 2：撒饵 / 制饵 / 已撒饵 / 卸力 / 钓具。
- 槽 3：收竿离开。
- 槽 4：`鱼护`，徽标显示当前鱼护份数；点击弹出鱼护清单（鱼种、份数、重量），空鱼护给出提示。与 `docs/固定五技能规范.md` 的钓位一行一致。
- 槽 5：空槽灰置。
