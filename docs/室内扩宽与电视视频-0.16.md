## 电视视频

视频由用户指定的 `ScreenRecording_11-12-2026 01-53-08_1.MP4` 转换，保持原文件不变。播放资产为 `assets/videos/home-tv.ogv`：Theora / Vorbis，854 × 480，24 fps，约 173.625 秒，约 62.8 MB。去除录屏两侧黑边，保留完整画面高度、字幕与声音。原始 MP4 已从所有导出预设排除。

使用 Godot 内置 VideoStreamPlayer 解码，视频纹理直接贴到电视屏幕，无额外 SubViewport。沙发面板提供开关、暂停/继续、音量增减，视频循环播放。关电视停止播放；离开别墅、去二楼、打开暂停界面或失焦时暂停解码。不开启后台音频。本次未在手机启动游戏做温度或功耗采样，不能据此宣称发热已消除。

更换片源：

```sh
python3 tools/prepare_tv_video.py '/绝对路径/视频.MP4'
```

需要含 libtheora / libvorbis 的 FFmpeg，本机使用独立的 `/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg`，不修改默认 FFmpeg 或 shell 配置。命令会覆盖电视播放资产；更新后重新导出应用。Godot 视频支持参考：[官方视频文档](https://docs.godotengine.org/en/latest/tutorials/animation/playing_videos.html)。
