# 悬浮伙伴（2026-11-17）

新增小云朵、小幽灵。开局与人物设置中可选择、命名、预览、保存；狗/猫/兔子和独自启程保留。旧档仍使用原伙伴，不重置世界。

## 来源与范围

小幽灵使用 Quaternius Ultimate Monsters 的 CC0 模型；具体下载镜像、官方授权和校验值见 assets/cc0-companions/SOURCES.md。小云朵为项目自制的 3D 几何模型，不宣称为下载的 Quaternius 云朵。两者均无第三方署名义务。需署名的鸟类、蝴蝶不在本次范围；未验证的萤火精灵、水滴精灵未添加。

## 行为

- 侧后方低空悬浮、缓慢起伏，随人物或船速追随；过远和切场景后回到人物附近。
- 目标方位与移动路径使用射线探测，必要时改用人物另一侧；不作为实体障碍阻挡玩家。不是完整飞行导航系统。
- 暂停时动作与漂浮时钟停止，上船后保持随船悬浮，不落水。
- 沿用原抚摸动作，伙伴降低高度便于接触；预留其他交互的路径时向侧方让开，取消后释放。
- 地面伙伴继续使用原 companion.gd，不套用空中行为。

## 五槽约定

靠近伙伴时槽 1 沿用抚摸，原范围/上船禁用条件保持；槽 2 奔跑、槽 3 建造以及槽 4/5 的原情境条件不变。没有新消耗和奖励，没有新增假技能。推杆与原取消流程继续取消抚摸。

## 验证边界

使用 headless 选角、存档、跟随、暂停、船上、找回和抚摸检查；不打开调试或游戏预览。真机外观、遮挡与复杂场景导航仍需体验验证。
