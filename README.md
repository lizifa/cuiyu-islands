# 晴耕雨航

独自住在小岛，日出而作、日落归家，周末双休；用捕鱼、种植和手工挣得生活，再驾船到镇上出售、换物，慢慢开通城市贸易。

Godot **4.7.2** / GDScript / Compatibility 渲染，目标为 Android / iOS 横屏全屏。项目目录暂保留 `cuiyu-islands`，游戏正式名称已改为《晴耕雨航》。这是可操作的生活贸易切片，已支持虚拟摇杆真实移动与附近对象交互；制造、订单和贸易仍使用面板，尚不是完整动作生存成品。

## 克隆后的本地准备

公开仓库不包含 Adobe Mixamo 的 `assets/mixamo-life/Drinking.fbx`、`Waving.fbx` 和生成的 `life_actions.tres`。当前 `scripts/life/home_gesture.gd` 预加载该动作库，因此首次运行前须通过自己的 Mixamo 账号获取相应动作，并按 [动作素材说明](assets/mixamo-life/README.md) 生成资源；仅克隆仓库不能直接运行完整游戏。本机现有素材不受影响。

构建产物、Godot 缓存、导出签名与本机导出预设不纳入版本控制。

## 运行

在 Godot 中导入本目录的 `project.godot`，按 F6/F5 运行主入口 `scenes/life_main.tscn`，或在 macOS 执行：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/lizifa/works/cuiyu-islands
```

出海探索：每岛有一个可见木码头，驶入金色泊位约1.8米内，点击右下上方「登岛」，船会摆正停稳后登岸；上岸后点击船形辅助按钮「返回船上」，回船后可「返航主岛」。

左下摇杆移动人物，右下大按钮与附近对象交互；按住「奔跑」加速，「建造」打开施工面板，背包入口统一放在右上。电脑也可用 WASD / 方向键走路。

找家：日期下方显示别墅方向与距离，点击「回家」自动步行返回；推摇杆随时接管。地图标注「别墅」「营地」。

默认使用稳定第三人称，展示完整人物和生活动作。左下摇杆移动，右侧空白区域拖动观察；松手停止，手动观察后不自动弹回，可点击「镜头回正」。镜头无走路颠簸、侧倾或奔跑变焦，靠墙安全收近并缓慢恢复。设置可手动切换第一人称；动作进行中暂不能切换。坐卧和钓鱼通过明确按钮起身或离开。

背包内「生活 · 制作 · 航行」集中打开劳作、建房、生活、航行、集市和日历。行动会推进游戏时间；Esc 或菜单中的按钮暂停，窗口失焦自动停止时间。关闭自动保存，也可主动点存档。详细菜单展开时暂停自然流逝，劳动面板中的行动仍按明确时长推进。

人物已改为 Kenney Animated Characters 三包共十二套可选外观，开局不按男女分类；旧档自动迁移，保留进度。详见 [人物替换说明](docs/Kenney人物替换.md)。

伙伴新增无需署名的小云朵和小幽灵，可在开局或人物设置中选择；详见 [悬浮伙伴](docs/悬浮伙伴.md)。

## 从新档开始

1. 用摇杆走近树木和石头，点击右下采集按钮；制造篝火，领取第一个里程碑。
2. 开局只有一个角色和待建房位置。采木与纤维搭临时庇护，过夜后继续建地基、墙体、屋顶和木门与床，完成自己的木屋。
3. 开局就有完好的小船，无需修理和材料。营地南侧木栈道尽头是自己的船；靠近点击上船，摇杆驾驶，返回码头靠岸。航行产生随速度变化的动态浪花，停船后逐渐消散。捕鱼后用篝火制作鱼干，每 2 鱼制 1 鱼干。
4. 先吃饭喝水再出海。08:00—18:00 去青湾镇卖货，4 鱼干可换 1 袋种子，每日一次。
5. 返岛建菜地播种，完成一张小镇订单，用劳动所得购买船舱，解锁临海城。

随时可免费喝水、短休；岛上可采果，小镇可喝应急热粥和免费借宿。夜间市场打烊，周末仍可出售换物，但不接生产订单。首张订单无期限，后续订单按工作日计时。

## 现有系统

- 24 分钟一个游戏日，行动额外推进时间；每周五天工作两天休息。
- 每季 14 日，每年 56 日；四季昼长、天气、售价、作物与生活消耗差异。
- 精力、饱食、饮水与健康，睡眠、食物、庇护与换季准备。
- 采集、捕鱼、制造、建筑、种植与一次性任务奖励。
- 岛屿 / 小镇 / 城市切换，营业时间、出售保底价、每日换物、商店升级、订单、账本。
- 自动存档、原子写入、备份恢复；测试不会改动正式存档。
- 26 个 Polyfork GLB（含开局角色、森林、动物与船） 实际导入；新手岛与市场场景、昼夜照明、篝火暖光和季节色彩。

## 开发验证默认不打开窗口

日常修改只执行带 `--headless` 的启动/测试，不自动打开游戏、编辑器或图形预览，以免影响其他开发。只有用户明确要求运行或预览时才打开窗口。当前简化HUD没有重新生成可视截图，文档中的旧截图属于历史版本。

当前HUD：左上三条生存状态、中上日期天气、右上背包/菜单、左侧一条当前任务；左下摇杆，右下交互/奔跑/建造。六项低频功能、手动保存、暂停与镜头归位收入菜单。普通结果提示4秒后消失，存档错误持续提示，自动保存正常完成时不弹提示。
